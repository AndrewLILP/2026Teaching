Lesson 6 of 12 · 50 minutes

Journal UI

Your journal remembers every photo, but players can't see it yet. Today you'll build the journal screen from your Lesson 2 storyboard: a scrolling grid that builds itself from the saved data, a detail panel for the selected photo, and a delete button that asks before doing anything permanent.

Producing & implementing
Last lesson: the Journal saved entries safely, reloaded and validated them, and gained a DeleteEntry method and a JournalChanged event. Today's screen uses both. It also reuses the "disable scripts and freeze time" pattern from Lesson 3.

Teaching advice

Timing: recap and vocabulary 4 min · gallery analysis 5 min · memory calculation 5 min · pseudocode and code walkthrough 10 min · bug detective 3 min · building the screen 18 min · checkpoint 5 min.

Build time: constructing the canvas is the longest part. Consider prebuilding the canvas hierarchy as a prefab for Foundation students, so they focus on wiring and testing.

Before class: when Unity offers to replace the EventSystem's old input module with Input System UI Input Module, accept it. Without it, buttons won't respond to the gamepad. Students also need TextMesh Pro, which Unity imports the first time a TMP text object is created.

Learning intentions

By the end of this lesson I can:

  • build interface elements at runtime from saved records
  • calculate memory use and justify using thumbnails
  • spread slow work across frames so the interface stays responsive
  • design a destructive action so players can't trigger it by accident.
Success criteria: my journal opens with J or the gamepad's select button, shows my photos newest first with their details, deletes only after I confirm, and can be used entirely with a gamepad.

Key vocabulary

Analysing

Deconstruct a gallery

You use photo galleries every day: on your phone, in Steam's screenshot manager, in social media apps. Their designers have solved the same problems you're about to face.

Analysis activity · pairs · 5 min

How does a gallery behave?

Open the photo gallery on a phone (or think about one you know well) and answer:

  1. What order are the photos in? Why that order?
  2. When you open an album with hundreds of photos, does every photo appear instantly at full quality? What do you see first?
  3. What happens when you press delete? How many steps does it take, and which button is easier to hit?
  4. What does an empty album show?
  1. Newest first: people usually want what they just took.
  2. Progressive loading: the grid appears straight away with blank tiles, then small previews fill in. Full-size images are never loaded for the grid.
  3. Confirm before deleting: a second step, with the safe choice selected by default.
  4. A helpful empty state: "No photos yet" plus how to take one.

Why thumbnails?

A PNG file is compressed on disk, but to display it, the game decodes it into raw pixels in memory: every pixel stored in full.

We do · calculation · 4 min

  1. A full photo is 1920 × 1080 pixels at 4 bytes per pixel (red, green, blue and transparency). How many bytes is one photo in memory?
  2. How much memory would a full journal of 50 photos use, in MB? (1 MB = 1,000,000 bytes.)
  3. Our thumbnails are 480 × 270 at 3 bytes per pixel (no transparency). How much do 50 thumbnails use?
  4. How many times less memory is that?
  1. 1920 × 1080 × 4 = 8,294,400 bytes, about 8.3 MB.
  2. 8,294,400 × 50 = 414,720,000 bytes, about 415 MB, just for one screen.
  3. 480 × 270 × 3 = 388,800 bytes each. × 50 = 19,440,000 bytes, about 19.4 MB.
  4. 414.72 ÷ 19.44 ≈ 21.3, so about 21 times less. Each thumbnail is a quarter of the width and a quarter of the height (1/16 of the pixels), and uses 3 bytes instead of 4.

480 × 270 is still sharp enough for the detail panel in our storyboard, so one small copy does both jobs.

Planning

Pseudocode first

NSW pseudocode · BuildGrid (progressive loading)

1   BEGIN BuildGrid
2       ClearGrid()
3       IF number of entries = 0 THEN
4           SHOW empty message
5           RETURN
6       ENDIF
7       FOR i FROM last entry DOWN TO first entry
8           CREATE thumbnail button for entry i
9       NEXT i
10      SELECT first button
11      FOR EACH button IN buttons
12          LOAD small copy of its photo
13          WAIT one frame
14      NEXT button
15  END BuildGrid

NSW pseudocode · deleting safely

1   BEGIN RequestDelete
2       IF selected = nothing THEN
3           RETURN
4       ENDIF
5       SHOW confirm panel
6       SELECT "No, keep it" button
7   END RequestDelete

8   BEGIN ConfirmDelete
9       HIDE confirm panel
10      Journal.DeleteEntry(selected entry)
11  END ConfirmDelete

Notice what ConfirmDelete doesn't do: it doesn't rebuild the grid. DeleteEntry raises JournalChanged, and the screen rebuilds whenever it hears that. One path for every change means one place for bugs to hide, not several.

Producing

Into C#

1Building the grid from data
private IEnumerator BuildGrid()
{
    ClearGrid();

    int count = journal.Entries.Count;
    countText.text = count == 1 ? "1 photo" : count + " photos";
    emptyMessage.SetActive(count == 0);
    if (count == 0)
    {
        ShowDetail(null);
        yield break;
    }

    // 1. Make every button now, newest first, so the layout appears at once.
    for (int i = count - 1; i >= 0; i--)
    {
        JournalThumbnail thumb = Instantiate(thumbnailPrefab, gridContent);
        thumb.Setup(journal.Entries[i], this);
        thumbnails.Add(thumb);
    }
    EventSystem.current.SetSelectedGameObject(thumbnails[0].gameObject);

    // 2. Load one photo per frame, so the screen never freezes.
    foreach (JournalThumbnail thumb in thumbnails)
    {
        thumb.SetTexture(LoadThumbnail(thumb.Entry));
        if (thumb == selected) detailImage.texture = thumb.Texture;
        yield return null;
    }
}
Part 1 creates every button immediately, so the layout appears at once. Part 2 loads one photo, then yield return null waits a frame before the next. Decoding a PNG takes a few milliseconds, so loading 50 in one frame would freeze the screen, but one per frame is unnoticeable.
2Loading and shrinking a photo
private Texture2D LoadThumbnail(JournalEntry entry)
{
    string path = Path.Combine(journal.PhotoFolder, entry.fileName);
    if (!File.Exists(path)) return null;        // guard clause

    Texture2D full = new Texture2D(2, 2);
    full.LoadImage(File.ReadAllBytes(path));    // decodes the PNG and resizes to fit
    Texture2D thumb = Shrink(full, thumbnailWidth, thumbnailHeight);
    Destroy(full);                              // keep only the small copy
    return thumb;
}

private static Texture2D Shrink(Texture2D source, int width, int height)
{
    RenderTexture temp = RenderTexture.GetTemporary(width, height);
    Graphics.Blit(source, temp);                // GPU draws the photo at the new size

    RenderTexture previous = RenderTexture.active;
    RenderTexture.active = temp;
    Texture2D small = new Texture2D(width, height, TextureFormat.RGB24, false);
    small.ReadPixels(new Rect(0, 0, width, height), 0, 0);
    small.Apply();

    RenderTexture.active = previous;
    RenderTexture.ReleaseTemporary(temp);
    return small;
}
Graphics.Blit asks the graphics card to draw the full photo onto a small temporary canvas (a RenderTexture). ReadPixels copies that small result back into a normal texture. The full-size texture is destroyed straight away, so only about 0.39 MB stays in memory per photo.
3Showing the details
public void ShowDetail(JournalThumbnail thumb)
{
    selected = thumb;
    if (thumb == null)
    {
        detailImage.texture = null;
        captionText.text = "";
        locationText.text = "";
        dateText.text = "";
        return;
    }

    JournalEntry entry = thumb.Entry;
    detailImage.texture = thumb.Texture;
    captionText.text = string.IsNullOrEmpty(entry.caption) ? "No caption yet" : entry.caption;
    locationText.text = entry.locationName;

    // Saved in one fixed format, shown in the player's own format.
    if (DateTime.TryParseExact(entry.timestamp, "yyyy-MM-ddTHH:mm:ss",
            CultureInfo.InvariantCulture, DateTimeStyles.None, out DateTime taken))
    {
        dateText.text = taken.ToString("g", CultureInfo.CurrentCulture);   // e.g. 2/10/2026 2:30 PM in Australia
    }
    else
    {
        dateText.text = "Unknown date";
    }
}
This closes a loop from Lesson 5. The timestamp was saved in one fixed format (InvariantCulture) so every computer reads it the same way. It's shown in the player's own format (CurrentCulture), so an Australian player sees day/month and an American player sees month/day. If the timestamp can't be read, TryParseExact returns false instead of crashing.
4Each thumbnail reports when it's selected
// Runs when this thumbnail is selected by mouse, keyboard or gamepad.
public void OnSelect(BaseEventData eventData)
{
    screen.ShowDetail(this);
}
ISelectHandler is an interface: a promise that this class has an OnSelect method. Unity calls it whenever the thumbnail gains focus, whether from a mouse click, the arrow keys or a gamepad. One method handles all three.
5Back means "back one step"
private void OnBack(InputAction.CallbackContext context)
{
    if (!IsOpen) return;                        // guard clause: nothing to go back from
    if (confirmPanel.activeSelf) CancelDelete(); // back out of the question first
    else Close();
}
If the delete question is showing, Back cancels it. Otherwise Back closes the journal. Players expect Back to undo the last thing, not everything.

Bug detective

The journal gets slower every time

A classmate's journal works, but in the Profiler their game's memory rises by about 19 MB every time they open and close it. After twenty visits the game stutters. Here's their ClearGrid:

private void ClearGrid()
{
    foreach (JournalThumbnail thumb in thumbnails)
    {
        Destroy(thumb.gameObject);
    }
    thumbnails.Clear();
}
Destroying a GameObject doesn't destroy textures created in code. Each visit creates 50 new thumbnail textures (about 19.4 MB, the figure you calculated) and never frees the old ones. That's a memory leak. Add if (thumb.Texture != null) Destroy(thumb.Texture); before destroying the GameObject. Any texture made with new Texture2D must be destroyed by your code.
Producing

Build the screen

Set the Game view to 1280 × 800 (Steam Deck) before you start, and keep your Lesson 2 storyboard beside you. This is the hierarchy you're aiming for:

JournalCanvas  (Canvas, Canvas Scaler: Scale With Screen Size, 1280 × 800)
├── Title          (TMP text: "Journal")
├── Count          (TMP text)
├── EmptyMessage   (TMP text: "No photos yet…", hidden)
├── GridScroll     (Scroll Rect, vertical only)
│   └── Viewport   (Mask)
│       └── Content (Grid Layout Group: cell 240 × 135, spacing 16;
│                    Content Size Fitter: vertical = Preferred Size)
├── DetailPanel
│   ├── DetailImage  (Raw Image)
│   ├── Caption      (TMP text)
│   ├── Location     (TMP text)
│   ├── Date         (TMP text)
│   └── DeleteButton (Button → OnClick: JournalScreen.RequestDelete)
├── PromptBar      (TMP text: "Ⓑ Back")
└── ConfirmPanel   (hidden)
    ├── Question   (TMP text: "Delete this photo? This can't be undone.")
    ├── YesButton  (→ JournalScreen.ConfirmDelete)
    └── NoButton   (→ JournalScreen.CancelDelete)

Setup · follow along · 15 min

  1. Thumbnail prefab: create a UI Button, delete its text, and add a child Raw Image stretched to fill it. Add JournalThumbnail to the Button and drag the Raw Image in. Set the Button's Selected Color to something bright. That's your focus outline from the storyboard. Drag it into a Prefabs folder and delete it from the scene.
  2. Build the canvas hierarchy above. Untick JournalCanvas so it starts hidden.
  3. Add JournalScreen to the PhotoMode object. Drag in every reference, including the prefab.
  4. Add your movement script, camera script, PhotoModeController and PhotoCapture to Disable While Open.
  5. Wire the three buttons' On Click events to the methods shown in the hierarchy.

Remember the 24 px rule

With the Game view at 1280 × 800, no text should be smaller than 24 px. Check the caption, location and date especially.

// Recommended filename: JournalScreen.cs
using System;
using System.Collections;
using System.Collections.Generic;
using System.Globalization;
using System.IO;
using TMPro;
using UnityEngine;
using UnityEngine.EventSystems;
using UnityEngine.InputSystem;
using UnityEngine.UI;

public class JournalScreen : MonoBehaviour
{
    [Header("Input (defaults are set when you add the component)")]
    [SerializeField] private InputAction toggleAction;
    [SerializeField] private InputAction backAction;

    [Header("Data and game")]
    [SerializeField] private Journal journal;
    [SerializeField] private PhotoModeController photoMode;
    [SerializeField] private Behaviour[] disableWhileOpen;  // movement, camera, PhotoModeController, PhotoCapture

    [Header("Grid")]
    [SerializeField] private GameObject screenRoot;         // the journal canvas
    [SerializeField] private Transform gridContent;         // ScrollRect content with a GridLayoutGroup
    [SerializeField] private JournalThumbnail thumbnailPrefab;
    [SerializeField] private GameObject emptyMessage;
    [SerializeField] private TMP_Text countText;
    [SerializeField] private int thumbnailWidth = 480;
    [SerializeField] private int thumbnailHeight = 270;

    [Header("Detail panel")]
    [SerializeField] private RawImage detailImage;
    [SerializeField] private TMP_Text captionText;
    [SerializeField] private TMP_Text locationText;
    [SerializeField] private TMP_Text dateText;

    [Header("Delete confirmation")]
    [SerializeField] private GameObject confirmPanel;
    [SerializeField] private Button confirmNoButton;

    public bool IsOpen { get; private set; }

    private readonly List<JournalThumbnail> thumbnails = new List<JournalThumbnail>();
    private JournalThumbnail selected;
    private float savedTimeScale = 1f;

    // Runs when the component is first added: fills in default controls.
    private void Reset()
    {
        toggleAction = new InputAction("ToggleJournal", InputActionType.Button);
        toggleAction.AddBinding("<Keyboard>/j");
        toggleAction.AddBinding("<Gamepad>/select");

        backAction = new InputAction("Back", InputActionType.Button);
        backAction.AddBinding("<Keyboard>/escape");
        backAction.AddBinding("<Gamepad>/buttonEast");
    }

    private void OnEnable()
    {
        toggleAction.performed += OnToggle;
        backAction.performed += OnBack;
        toggleAction.Enable();
        backAction.Enable();
        journal.JournalChanged += OnJournalChanged;
    }

    private void OnDisable()
    {
        toggleAction.performed -= OnToggle;
        backAction.performed -= OnBack;
        toggleAction.Disable();
        backAction.Disable();
        journal.JournalChanged -= OnJournalChanged;
    }

    private void OnToggle(InputAction.CallbackContext context)
    {
        if (IsOpen) Close();
        else Open();
    }

    private void OnBack(InputAction.CallbackContext context)
    {
        if (!IsOpen) return;                        // guard clause: nothing to go back from
        if (confirmPanel.activeSelf) CancelDelete(); // back out of the question first
        else Close();
    }

    private void Open()
    {
        if (photoMode != null && photoMode.IsActive) return;   // guard clause: finish photo mode first

        IsOpen = true;
        foreach (Behaviour script in disableWhileOpen)
        {
            script.enabled = false;
        }
        savedTimeScale = Time.timeScale;
        Time.timeScale = 0f;

        screenRoot.SetActive(true);
        confirmPanel.SetActive(false);
        StartCoroutine(BuildGrid());
    }

    private void Close()
    {
        StopAllCoroutines();
        ClearGrid();
        screenRoot.SetActive(false);

        Time.timeScale = savedTimeScale;
        foreach (Behaviour script in disableWhileOpen)
        {
            script.enabled = true;
        }
        IsOpen = false;
    }

    private void OnJournalChanged()
    {
        if (!IsOpen) return;                        // guard clause
        StopAllCoroutines();
        StartCoroutine(BuildGrid());
    }

    private IEnumerator BuildGrid()
    {
        ClearGrid();

        int count = journal.Entries.Count;
        countText.text = count == 1 ? "1 photo" : count + " photos";
        emptyMessage.SetActive(count == 0);
        if (count == 0)
        {
            ShowDetail(null);
            yield break;
        }

        // 1. Make every button now, newest first, so the layout appears at once.
        for (int i = count - 1; i >= 0; i--)
        {
            JournalThumbnail thumb = Instantiate(thumbnailPrefab, gridContent);
            thumb.Setup(journal.Entries[i], this);
            thumbnails.Add(thumb);
        }
        EventSystem.current.SetSelectedGameObject(thumbnails[0].gameObject);

        // 2. Load one photo per frame, so the screen never freezes.
        foreach (JournalThumbnail thumb in thumbnails)
        {
            thumb.SetTexture(LoadThumbnail(thumb.Entry));
            if (thumb == selected) detailImage.texture = thumb.Texture;
            yield return null;
        }
    }

    private void ClearGrid()
    {
        foreach (JournalThumbnail thumb in thumbnails)
        {
            if (thumb.Texture != null) Destroy(thumb.Texture);   // free its memory
            Destroy(thumb.gameObject);
        }
        thumbnails.Clear();
        selected = null;
        detailImage.texture = null;
    }

    private Texture2D LoadThumbnail(JournalEntry entry)
    {
        string path = Path.Combine(journal.PhotoFolder, entry.fileName);
        if (!File.Exists(path)) return null;        // guard clause

        Texture2D full = new Texture2D(2, 2);
        full.LoadImage(File.ReadAllBytes(path));    // decodes the PNG and resizes to fit
        Texture2D thumb = Shrink(full, thumbnailWidth, thumbnailHeight);
        Destroy(full);                              // keep only the small copy
        return thumb;
    }

    private static Texture2D Shrink(Texture2D source, int width, int height)
    {
        RenderTexture temp = RenderTexture.GetTemporary(width, height);
        Graphics.Blit(source, temp);                // GPU draws the photo at the new size

        RenderTexture previous = RenderTexture.active;
        RenderTexture.active = temp;
        Texture2D small = new Texture2D(width, height, TextureFormat.RGB24, false);
        small.ReadPixels(new Rect(0, 0, width, height), 0, 0);
        small.Apply();

        RenderTexture.active = previous;
        RenderTexture.ReleaseTemporary(temp);
        return small;
    }

    public void ShowDetail(JournalThumbnail thumb)
    {
        selected = thumb;
        if (thumb == null)
        {
            detailImage.texture = null;
            captionText.text = "";
            locationText.text = "";
            dateText.text = "";
            return;
        }

        JournalEntry entry = thumb.Entry;
        detailImage.texture = thumb.Texture;
        captionText.text = string.IsNullOrEmpty(entry.caption) ? "No caption yet" : entry.caption;
        locationText.text = entry.locationName;

        // Saved in one fixed format, shown in the player's own format.
        if (DateTime.TryParseExact(entry.timestamp, "yyyy-MM-ddTHH:mm:ss",
                CultureInfo.InvariantCulture, DateTimeStyles.None, out DateTime taken))
        {
            dateText.text = taken.ToString("g", CultureInfo.CurrentCulture);   // e.g. 2/10/2026 2:30 PM in Australia
        }
        else
        {
            dateText.text = "Unknown date";
        }
    }

    // Delete button: ask first.
    public void RequestDelete()
    {
        if (selected == null) return;               // guard clause
        confirmPanel.SetActive(true);
        EventSystem.current.SetSelectedGameObject(confirmNoButton.gameObject);  // safe default
    }

    // "Yes, delete" button.
    public void ConfirmDelete()
    {
        confirmPanel.SetActive(false);
        if (selected == null) return;               // guard clause
        journal.DeleteEntry(selected.Entry);        // raises JournalChanged, which rebuilds the grid
    }

    // "No, keep it" button.
    public void CancelDelete()
    {
        confirmPanel.SetActive(false);
        if (selected != null) EventSystem.current.SetSelectedGameObject(selected.gameObject);
    }
}
// Recommended filename: JournalThumbnail.cs
using UnityEngine;
using UnityEngine.EventSystems;
using UnityEngine.UI;

public class JournalThumbnail : MonoBehaviour, ISelectHandler
{
    [SerializeField] private RawImage image;

    public JournalEntry Entry { get; private set; }
    public Texture2D Texture { get; private set; }

    private JournalScreen screen;

    public void Setup(JournalEntry entry, JournalScreen owner)
    {
        Entry = entry;
        screen = owner;
        image.texture = null;            // grey until the photo loads
    }

    public void SetTexture(Texture2D texture)
    {
        Texture = texture;
        image.texture = texture;
    }

    // Runs when this thumbnail is selected by mouse, keyboard or gamepad.
    public void OnSelect(BaseEventData eventData)
    {
        screen.ShowDetail(this);
    }
}

Core

Extension

Open instantly

  • The journal reloads every thumbnail each time it opens. Keep them in a Dictionary<string, Texture2D> keyed by file name, so only new photos are loaded.
  • Remember to destroy a cached texture when its photo is deleted. Otherwise you've built a new leak.
  • Measure how long the grid takes to fill, before and after.
