Lesson 7 of 12 · 50 minutes

Controller-first input

Your controls are scattered across four scripts. That worked while building, but it's hard to change and impossible to see in one place. Today you'll refactor: move every control into one Input Action Asset without changing what the game does, then prove nothing broke. Along the way, you'll add mouse look, prompts that switch between keyboard and gamepad, and a journal that scrolls itself for gamepad players.

Producing & implementing Testing & evaluating
Last lesson: the journal screen built itself from saved data and asked before deleting. Every script so far has created its own controls in a Reset method. Today those controls move to one shared asset.

Teaching advice

Timing: recap and vocabulary 4 min · control audit 5 min · asset and refactor 12 min · mouse look and bug detective 7 min · prompts and scrolling 7 min · regression testing 10 min · checkpoint 5 min.

Ready-made asset: PhotoJournalControls.inputactions is in the unit's code folder. Students can drag it into Assets instead of building it from the table, which saves about 10 minutes. Building it by hand is good Core practice.

Why a separate asset? Unity 6 projects come with a project-wide InputSystem_Actions asset. We keep our own so the photo journal stays self-contained and can be moved into another game, which is low coupling again.

Name it: this lesson introduces regression testing by name. Students re-run tests from Lessons 3–6 after changing code that already worked.

Learning intentions

By the end of this lesson I can:

  • refactor code to use a single source of truth, without changing what it does
  • explain why mouse and stick input need different calculations
  • make on-screen prompts match the device the player is using
  • use regression testing to prove a refactor broke nothing.
Success criteria: every control lives in one asset, mouse look feels the same at any frame rate, prompts switch when I swap devices, the journal scrolls to follow the gamepad, and every earlier test still passes.

Planning

One home for every control

An Input Action Asset is a file that holds every action and binding. It becomes the single source of truth for controls: change a binding there and every script that uses it changes too. Ours has two action maps.

MapActionTypeKeyboard & MouseGamepad
PhotoTogglePhotoModeButtonPNorth button (Y)
CaptureButtonSpaceSouth button (A)
MoveValue · Vector2WASDLeft stick
LookValue · Vector2Mouse delta, arrow keysRight stick
JournalToggleJournalButtonJSelect (View)
BackButtonEscapeEast button (B)

Gamepad bindings use positions (north, south, east), not letters, so one binding works on Xbox, PlayStation and Steam Deck controllers. Steam Deck's face buttons use the same A, B, X, Y layout as an Xbox controller.

Producing

The refactor

Each script changes in the same three small ways. Here's PhotoModeController. PhotoCapture and JournalScreen follow exactly the same pattern.

1Change the field type
BEFORE (Lesson 3)
[Header("Input (defaults are set when you add the component)")]
[SerializeField] private InputAction toggleAction;
[SerializeField] private InputAction moveAction;
[SerializeField] private InputAction lookAction;
AFTER
[Header("Input (from the PhotoJournalControls asset)")]
[SerializeField] private InputActionReference toggleAction;
[SerializeField] private InputActionReference moveAction;
[SerializeField] private InputActionReference lookAction;
An InputActionReference doesn't hold its own bindings. It points to an action in the asset. In the Inspector, you drag each action from the asset into its slot.
2Add .action wherever the field is used
private void OnEnable()
{
    toggleAction.action.performed += OnToggle;
    toggleAction.action.Enable();
    moveAction.action.Enable();
    lookAction.action.Enable();
}
The reference is a signpost. .action follows it to the real action. Everything else about the action works the same.
3Delete the Reset method
The default bindings now live in the asset, so Reset has nothing left to do. Deleting code you no longer need is part of refactoring. Less code means fewer places for bugs.

Mouse look

The asset already binds mouse delta to Look. But a mouse and a stick report different kinds of value:

DeviceWhat it reportsExampleSo the camera turns by…
Stick or arrow keysA rate: how hard it's pushed, from −1 to 1Held fully right gives 1, 1, 1 every framevalue × lookSpeed × dt
MouseA distance: pixels moved since last frameA quick flick might give 40, 120, 60, 0value × mouseSensitivity

NSW pseudocode · turning the camera

1   SET look TO Look action value
2   IF look came from a mouse THEN
3       SET lookScale TO mouseSensitivity
4   ELSE
5       SET lookScale TO lookSpeed × dt
6   ENDIF
7   SET yaw TO yaw + look.x × lookScale
8   SET pitch TO pitch − look.y × lookScale
4LateUpdate, now device-aware
private void LateUpdate()
{
    if (!IsActive) return;               // guard clause

    float dt = Time.unscaledDeltaTime;   // keeps ticking while time is frozen

    Vector2 look = lookAction.action.ReadValue<Vector2>();
    bool fromMouse = lookAction.action.activeControl?.device is Mouse;
    // A mouse reports how far it moved this frame. A stick reports a steady rate.
    float lookScale = fromMouse ? mouseSensitivity : lookSpeed * dt;
    yaw += look.x * lookScale;
    pitch -= look.y * lookScale;
    pitch = Mathf.Clamp(pitch, minPitch, maxPitch);
    Quaternion rotation = Quaternion.Euler(pitch, yaw, 0f);

    Vector2 move = moveAction.action.ReadValue<Vector2>();
    Vector3 step = rotation * new Vector3(move.x, 0f, move.y) * moveSpeed * dt;
    offset = Vector3.ClampMagnitude(offset + step, maxDistance);

    cameraTransform.SetPositionAndRotation(pivot.position + offset, rotation);
}
activeControl is the physical control that produced the value. ?. means "only if it isn't null", because nothing is active when no one is touching the controls. EnterPhotoMode now also locks the cursor so the mouse turns the camera instead of moving a pointer, and ExitPhotoMode puts it back.

Desk check: does frame rate matter?

The player sweeps the mouse 600 pixels to the right over exactly one second. lookSpeed = 90, mouseSensitivity = 0.1. The school PC runs at 60 fps and a Steam Deck in a busy area at 30 fps.

Formula60 fps30 fpsNote
600 × lookSpeed × dt (stick formula)600 × 90 × 1/60 = 900°600 × 90 × 1/30 = 1800°Wildly fast, and doubles at 30 fps
600 × mouseSensitivity (mouse formula)600 × 0.1 = 60°600 × 0.1 = 60°Same at any frame rate

The total distance the mouse moves doesn't depend on frame rate, so the turn shouldn't either. Multiplying a distance by dt ties it to frame rate. Multiplying a rate by dt is what removes that link.

Bug detective

Twice as twitchy on Steam Deck

A classmate added <Mouse>/delta to Look in the asset but didn't change their code. On the school PC, mouse look is very fast but usable once they turned lookSpeed down. On a Steam Deck with its trackpad set up as a mouse, in a busy scene running at 30 fps, it turns twice as far for the same thumb movement.

Vector2 look = lookAction.action.ReadValue<Vector2>();
yaw += look.x * lookSpeed * dt;
pitch -= look.y * lookSpeed * dt;
The mouse distance is being treated like a stick rate and multiplied by dt. At 30 fps, dt is twice as big, so the same mouse movement turns the camera twice as far, as the desk check shows. Turning lookSpeed down only hid the problem on one machine. The fix is the device check from step 4: mouse distance × mouseSensitivity, with no dt.

Prompts that follow the player

If a player picks up a gamepad but the screen still says "Press Space", the game feels broken. Steam Deck reviews check that prompts match the controller. Two small scripts solve this: one watches which device was used last, and one updates each prompt.

NSW pseudocode · watching for device changes

1   BEGIN OnAnyButton(control)
2       SET isGamepad TO (control's device is a gamepad)
3       IF isGamepad = usingGamepad THEN
4           RETURN
5       ENDIF
6       SET usingGamepad TO isGamepad
7       SEND message "device changed"
8   END OnAnyButton
5InputDeviceWatcher.cs
// Recommended filename: InputDeviceWatcher.cs
using System;
using UnityEngine;
using UnityEngine.InputSystem;

public class InputDeviceWatcher : MonoBehaviour
{
    public static bool UsingGamepad { get; private set; }
    public static event Action DeviceChanged;

    private IDisposable listener;

    private void Awake()
    {
        UsingGamepad = Gamepad.current != null;     // e.g. Steam Deck starts on gamepad prompts
    }

    private void OnEnable()
    {
        listener = InputSystem.onAnyButtonPress.Call(OnAnyButton);
    }

    private void OnDisable()
    {
        listener?.Dispose();
    }

    private void OnAnyButton(InputControl control)
    {
        bool isGamepad = control.device is Gamepad;
        if (isGamepad == UsingGamepad) return;      // guard clause: same device as before
        UsingGamepad = isGamepad;
        DeviceChanged?.Invoke();
    }
}
static means there's one shared value for the whole game, so any script can read InputDeviceWatcher.UsingGamepad without needing a reference. Awake starts in gamepad mode if one is connected, so a Steam Deck shows the right prompts before the first button is pressed. The guard clause means prompts only redraw when the device actually changes.
6PromptLabel.cs, added to any prompt text
// Recommended filename: PromptLabel.cs
using TMPro;
using UnityEngine;

[RequireComponent(typeof(TMP_Text))]
public class PromptLabel : MonoBehaviour
{
    [SerializeField] private string keyboardText = "[Space] Capture   [P] Exit";
    [SerializeField] private string gamepadText = "[A] Capture   [Y] Exit";

    private TMP_Text label;

    private void Awake()
    {
        label = GetComponent<TMP_Text>();
    }

    private void OnEnable()
    {
        InputDeviceWatcher.DeviceChanged += Refresh;
        Refresh();
    }

    private void OnDisable()
    {
        InputDeviceWatcher.DeviceChanged -= Refresh;
    }

    private void Refresh()
    {
        label.text = InputDeviceWatcher.UsingGamepad ? gamepadText : keyboardText;
    }
}
This is the same event pattern as PhotoSaved and JournalChanged: the watcher announces, and every prompt label listens. Add one PromptLabel to each prompt and type its two versions in the Inspector.

Why [A] and not Ⓐ?

TextMesh Pro's default font has no circled letters, so Ⓐ shows as an empty box. Use [A] for now. The Extension task swaps in proper button icons.

Keeping focus on screen

Try the Lesson 6 journal with a gamepad and more than two rows of photos. Press down past the last visible row and the selection disappears off the bottom. A mouse player would scroll, but a gamepad player can't. When a thumbnail is selected, the grid must move to show it.

7JournalScreen.cs: KeepVisible
ADD TO JournalScreen, AND CALL IT FROM JournalThumbnail.OnSelect
// Scrolls the grid just enough to keep a selected thumbnail on screen.
public void KeepVisible(RectTransform item)
{
    Vector3[] itemCorners = new Vector3[4];     // 0 = bottom-left, 1 = top-left
    Vector3[] viewCorners = new Vector3[4];
    item.GetWorldCorners(itemCorners);
    gridScroll.viewport.GetWorldCorners(viewCorners);

    float belowBottom = viewCorners[0].y - itemCorners[0].y;
    float aboveTop = itemCorners[1].y - viewCorners[1].y;

    float shift = 0f;
    if (belowBottom > 0f) shift = belowBottom;      // item hidden below: move content up
    else if (aboveTop > 0f) shift = -aboveTop;      // item hidden above: move content down
    if (shift == 0f) return;                        // guard clause: already visible

    gridScroll.StopMovement();
    gridScroll.content.position += new Vector3(0f, shift, 0f);
}

// Runs when this thumbnail is selected by mouse, keyboard or gamepad.
public void OnSelect(BaseEventData eventData)
{
    screen.ShowDetail(this);
    screen.KeepVisible((RectTransform)transform);   // gamepad users can't scroll by hand
}
It compares the thumbnail's bottom and top edges with the visible window's edges. If the thumbnail pokes out below, the content moves up by exactly that much. If it pokes out above, the content moves down. Otherwise the guard clause returns. Set the ScrollRect's Movement Type to Clamped so it never scrolls past the ends.

// Recommended filename: PhotoModeController.cs
using UnityEngine;
using UnityEngine.InputSystem;

public class PhotoModeController : MonoBehaviour
{
    [Header("Input (from the PhotoJournalControls asset)")]
    [SerializeField] private InputActionReference toggleAction;
    [SerializeField] private InputActionReference moveAction;
    [SerializeField] private InputActionReference lookAction;

    [Header("Scene references")]
    [SerializeField] private Transform cameraTransform;   // your main camera
    [SerializeField] private Transform pivot;             // an empty object at the hiker's head
    [SerializeField] private GameObject hud;              // your HUD canvas
    [SerializeField] private Behaviour[] disableWhileActive; // movement and camera-follow scripts

    [Header("Camera limits")]
    [SerializeField] private float maxDistance = 4f;      // metres from the pivot
    [SerializeField] private float moveSpeed = 2f;        // metres per second
    [SerializeField] private float lookSpeed = 90f;       // stick: degrees per second
    [SerializeField] private float mouseSensitivity = 0.1f; // mouse: degrees per pixel moved
    [SerializeField] private float minPitch = -60f;
    [SerializeField] private float maxPitch = 70f;

    public bool IsActive { get; private set; }

    private bool isAvailable;
    private Vector3 offset;
    private float yaw;
    private float pitch;
    private Vector3 savedPosition;
    private Quaternion savedRotation;
    private float savedTimeScale = 1f;
    private CursorLockMode savedCursorLock;

    private void OnEnable()
    {
        toggleAction.action.performed += OnToggle;
        toggleAction.action.Enable();
        moveAction.action.Enable();
        lookAction.action.Enable();
    }

    private void OnDisable()
    {
        toggleAction.action.performed -= OnToggle;
        toggleAction.action.Disable();
        moveAction.action.Disable();
        lookAction.action.Disable();
    }

    // THE HOOK: your own player code calls this.
    public void SetAvailable(bool available)
    {
        isAvailable = available;
        if (!isAvailable && IsActive)
        {
            ExitPhotoMode();   // forced out, e.g. a cutscene starts
        }
    }

    private void OnToggle(InputAction.CallbackContext context)
    {
        if (!isAvailable) return;            // guard clause

        if (IsActive) ExitPhotoMode();
        else EnterPhotoMode();
    }

    private void EnterPhotoMode()
    {
        IsActive = true;

        savedPosition = cameraTransform.position;
        savedRotation = cameraTransform.rotation;

        foreach (Behaviour script in disableWhileActive)
        {
            script.enabled = false;
        }
        if (hud != null) hud.SetActive(false);

        offset = Vector3.ClampMagnitude(cameraTransform.position - pivot.position, maxDistance);
        yaw = cameraTransform.eulerAngles.y;
        pitch = NormaliseAngle(cameraTransform.eulerAngles.x);

        savedTimeScale = Time.timeScale;
        Time.timeScale = 0f;                 // freeze the world

        savedCursorLock = Cursor.lockState;
        Cursor.lockState = CursorLockMode.Locked;   // the mouse turns the camera, not a pointer
    }

    private void ExitPhotoMode()
    {
        IsActive = false;
        Cursor.lockState = savedCursorLock;
        Time.timeScale = savedTimeScale;

        cameraTransform.SetPositionAndRotation(savedPosition, savedRotation);
        if (hud != null) hud.SetActive(true);

        foreach (Behaviour script in disableWhileActive)
        {
            script.enabled = true;
        }
    }

    private void LateUpdate()
    {
        if (!IsActive) return;               // guard clause

        float dt = Time.unscaledDeltaTime;   // keeps ticking while time is frozen

        Vector2 look = lookAction.action.ReadValue<Vector2>();
        bool fromMouse = lookAction.action.activeControl?.device is Mouse;
        // A mouse reports how far it moved this frame. A stick reports a steady rate.
        float lookScale = fromMouse ? mouseSensitivity : lookSpeed * dt;
        yaw += look.x * lookScale;
        pitch -= look.y * lookScale;
        pitch = Mathf.Clamp(pitch, minPitch, maxPitch);
        Quaternion rotation = Quaternion.Euler(pitch, yaw, 0f);

        Vector2 move = moveAction.action.ReadValue<Vector2>();
        Vector3 step = rotation * new Vector3(move.x, 0f, move.y) * moveSpeed * dt;
        offset = Vector3.ClampMagnitude(offset + step, maxDistance);

        cameraTransform.SetPositionAndRotation(pivot.position + offset, rotation);
    }

    private static float NormaliseAngle(float angle)
    {
        return angle > 180f ? angle - 360f : angle;
    }
}
// Recommended filename: PhotoCapture.cs
using System;
using System.Collections;
using System.IO;
using UnityEngine;
using UnityEngine.InputSystem;
using UnityEngine.UI;

public class PhotoCapture : MonoBehaviour
{
    [Header("Input (from the PhotoJournalControls asset)")]
    [SerializeField] private InputActionReference captureAction;

    [Header("Scene references")]
    [SerializeField] private PhotoModeController photoMode;
    [SerializeField] private Journal journal;
    [SerializeField] private GameObject journalFullMessage; // hidden "Journal full" text
    [SerializeField] private GameObject photoModeOverlay;   // button prompts shown in photo mode
    [SerializeField] private AudioSource shutterSound;
    [SerializeField] private Image flashImage;              // full-screen white Image on its own canvas

    [Header("Feedback")]
    [SerializeField] private float flashDuration = 0.25f;   // seconds

    // Lesson 5's journal listens for this.
    public event Action<string> PhotoSaved;

    private bool isCapturing;
    private string photoFolder;

    private void Awake()
    {
        photoFolder = Path.Combine(Application.persistentDataPath, "Journal");
        Directory.CreateDirectory(photoFolder);     // does nothing if it already exists
        Debug.Log("Photos are saved to: " + photoFolder);
    }

    private void OnEnable()
    {
        captureAction.action.performed += OnCapture;
        captureAction.action.Enable();
    }

    private void OnDisable()
    {
        captureAction.action.performed -= OnCapture;
        captureAction.action.Disable();
    }

    // Keeps the photo mode prompts in step with photo mode.
    private void Update()
    {
        if (photoModeOverlay == null || isCapturing) return;   // guard clause
        photoModeOverlay.SetActive(photoMode.IsActive);
    }

    private void OnCapture(InputAction.CallbackContext context)
    {
        if (!photoMode.IsActive) return;     // guard clause: not in photo mode
        if (isCapturing) return;             // guard clause: already taking a photo
        if (journal != null && journal.IsFull)   // guard clause: no room left
        {
            StartCoroutine(ShowFullMessage());
            return;
        }
        StartCoroutine(CaptureRoutine());
    }

    private IEnumerator ShowFullMessage()
    {
        if (journalFullMessage == null) yield break;   // guard clause
        journalFullMessage.SetActive(true);
        yield return new WaitForSecondsRealtime(2f);   // real seconds: the world is frozen
        journalFullMessage.SetActive(false);
    }

    private IEnumerator CaptureRoutine()
    {
        isCapturing = true;
        if (photoModeOverlay != null) photoModeOverlay.SetActive(false);

        yield return new WaitForEndOfFrame();       // wait until the frame is fully drawn

        Texture2D shot = ScreenCapture.CaptureScreenshotAsTexture();
        byte[] png = shot.EncodeToPNG();
        Destroy(shot);                              // free the texture's memory

        string fileName = MakeUniqueFileName();
        File.WriteAllBytes(Path.Combine(photoFolder, fileName), png);

        if (shutterSound != null) shutterSound.Play();
        yield return Flash();

        PhotoSaved?.Invoke(fileName);
        isCapturing = false;
    }

    private string MakeUniqueFileName()
    {
        string baseName = "photo_" + DateTime.Now.ToString("yyyyMMdd_HHmmss");
        string fileName = baseName + ".png";
        int copy = 2;
        while (File.Exists(Path.Combine(photoFolder, fileName)))   // same second? add a number
        {
            fileName = baseName + "_" + copy + ".png";
            copy++;
        }
        return fileName;
    }

    private IEnumerator Flash()
    {
        if (flashImage == null) yield break;        // guard clause

        float elapsed = 0f;
        while (elapsed < flashDuration)
        {
            elapsed += Time.unscaledDeltaTime;      // real time: the world is frozen
            float alpha = 1f - (elapsed / flashDuration);
            flashImage.color = new Color(1f, 1f, 1f, alpha);
            yield return null;                      // wait one frame
        }
        flashImage.color = new Color(1f, 1f, 1f, 0f);
    }
}
// Recommended filename: JournalScreen.cs
using System;
using System.Collections;
using System.Collections.Generic;
using System.Globalization;
using System.IO;
using TMPro;
using UnityEngine;
using UnityEngine.EventSystems;
using UnityEngine.InputSystem;
using UnityEngine.UI;

public class JournalScreen : MonoBehaviour
{
    [Header("Input (from the PhotoJournalControls asset)")]
    [SerializeField] private InputActionReference toggleAction;
    [SerializeField] private InputActionReference backAction;

    [Header("Data and game")]
    [SerializeField] private Journal journal;
    [SerializeField] private PhotoModeController photoMode;
    [SerializeField] private Behaviour[] disableWhileOpen;  // movement, camera, PhotoModeController, PhotoCapture

    [Header("Grid")]
    [SerializeField] private GameObject screenRoot;         // the journal canvas
    [SerializeField] private ScrollRect gridScroll;         // set Movement Type to Clamped
    [SerializeField] private Transform gridContent;         // ScrollRect content with a GridLayoutGroup
    [SerializeField] private JournalThumbnail thumbnailPrefab;
    [SerializeField] private GameObject emptyMessage;
    [SerializeField] private TMP_Text countText;
    [SerializeField] private int thumbnailWidth = 480;
    [SerializeField] private int thumbnailHeight = 270;

    [Header("Detail panel")]
    [SerializeField] private RawImage detailImage;
    [SerializeField] private TMP_Text captionText;
    [SerializeField] private TMP_Text locationText;
    [SerializeField] private TMP_Text dateText;

    [Header("Delete confirmation")]
    [SerializeField] private GameObject confirmPanel;
    [SerializeField] private Button confirmNoButton;

    public bool IsOpen { get; private set; }

    private readonly List<JournalThumbnail> thumbnails = new List<JournalThumbnail>();
    private JournalThumbnail selected;
    private float savedTimeScale = 1f;

    private void OnEnable()
    {
        toggleAction.action.performed += OnToggle;
        backAction.action.performed += OnBack;
        toggleAction.action.Enable();
        backAction.action.Enable();
        journal.JournalChanged += OnJournalChanged;
    }

    private void OnDisable()
    {
        toggleAction.action.performed -= OnToggle;
        backAction.action.performed -= OnBack;
        toggleAction.action.Disable();
        backAction.action.Disable();
        journal.JournalChanged -= OnJournalChanged;
    }

    private void OnToggle(InputAction.CallbackContext context)
    {
        if (IsOpen) Close();
        else Open();
    }

    private void OnBack(InputAction.CallbackContext context)
    {
        if (!IsOpen) return;                        // guard clause: nothing to go back from
        if (confirmPanel.activeSelf) CancelDelete(); // back out of the question first
        else Close();
    }

    private void Open()
    {
        if (photoMode != null && photoMode.IsActive) return;   // guard clause: finish photo mode first

        IsOpen = true;
        foreach (Behaviour script in disableWhileOpen)
        {
            script.enabled = false;
        }
        savedTimeScale = Time.timeScale;
        Time.timeScale = 0f;

        screenRoot.SetActive(true);
        confirmPanel.SetActive(false);
        StartCoroutine(BuildGrid());
    }

    private void Close()
    {
        StopAllCoroutines();
        ClearGrid();
        screenRoot.SetActive(false);

        Time.timeScale = savedTimeScale;
        foreach (Behaviour script in disableWhileOpen)
        {
            script.enabled = true;
        }
        IsOpen = false;
    }

    private void OnJournalChanged()
    {
        if (!IsOpen) return;                        // guard clause
        StopAllCoroutines();
        StartCoroutine(BuildGrid());
    }

    private IEnumerator BuildGrid()
    {
        ClearGrid();

        int count = journal.Entries.Count;
        countText.text = count == 1 ? "1 photo" : count + " photos";
        emptyMessage.SetActive(count == 0);
        if (count == 0)
        {
            ShowDetail(null);
            yield break;
        }

        // 1. Make every button now, newest first, so the layout appears at once.
        for (int i = count - 1; i >= 0; i--)
        {
            JournalThumbnail thumb = Instantiate(thumbnailPrefab, gridContent);
            thumb.Setup(journal.Entries[i], this);
            thumbnails.Add(thumb);
        }
        EventSystem.current.SetSelectedGameObject(thumbnails[0].gameObject);

        // 2. Load one photo per frame, so the screen never freezes.
        foreach (JournalThumbnail thumb in thumbnails)
        {
            thumb.SetTexture(LoadThumbnail(thumb.Entry));
            if (thumb == selected) detailImage.texture = thumb.Texture;
            yield return null;
        }
    }

    private void ClearGrid()
    {
        foreach (JournalThumbnail thumb in thumbnails)
        {
            if (thumb.Texture != null) Destroy(thumb.Texture);   // free its memory
            Destroy(thumb.gameObject);
        }
        thumbnails.Clear();
        selected = null;
        detailImage.texture = null;
    }

    private Texture2D LoadThumbnail(JournalEntry entry)
    {
        string path = Path.Combine(journal.PhotoFolder, entry.fileName);
        if (!File.Exists(path)) return null;        // guard clause

        Texture2D full = new Texture2D(2, 2);
        full.LoadImage(File.ReadAllBytes(path));    // decodes the PNG and resizes to fit
        Texture2D thumb = Shrink(full, thumbnailWidth, thumbnailHeight);
        Destroy(full);                              // keep only the small copy
        return thumb;
    }

    private static Texture2D Shrink(Texture2D source, int width, int height)
    {
        RenderTexture temp = RenderTexture.GetTemporary(width, height);
        Graphics.Blit(source, temp);                // GPU draws the photo at the new size

        RenderTexture previous = RenderTexture.active;
        RenderTexture.active = temp;
        Texture2D small = new Texture2D(width, height, TextureFormat.RGB24, false);
        small.ReadPixels(new Rect(0, 0, width, height), 0, 0);
        small.Apply();

        RenderTexture.active = previous;
        RenderTexture.ReleaseTemporary(temp);
        return small;
    }

    public void ShowDetail(JournalThumbnail thumb)
    {
        selected = thumb;
        if (thumb == null)
        {
            detailImage.texture = null;
            captionText.text = "";
            locationText.text = "";
            dateText.text = "";
            return;
        }

        JournalEntry entry = thumb.Entry;
        detailImage.texture = thumb.Texture;
        captionText.text = string.IsNullOrEmpty(entry.caption) ? "No caption yet" : entry.caption;
        locationText.text = entry.locationName;

        // Saved in one fixed format, shown in the player's own format.
        if (DateTime.TryParseExact(entry.timestamp, "yyyy-MM-ddTHH:mm:ss",
                CultureInfo.InvariantCulture, DateTimeStyles.None, out DateTime taken))
        {
            dateText.text = taken.ToString("g", CultureInfo.CurrentCulture);   // e.g. 2/10/2026 2:30 PM in Australia
        }
        else
        {
            dateText.text = "Unknown date";
        }
    }

    // Scrolls the grid just enough to keep a selected thumbnail on screen.
    public void KeepVisible(RectTransform item)
    {
        Vector3[] itemCorners = new Vector3[4];     // 0 = bottom-left, 1 = top-left
        Vector3[] viewCorners = new Vector3[4];
        item.GetWorldCorners(itemCorners);
        gridScroll.viewport.GetWorldCorners(viewCorners);

        float belowBottom = viewCorners[0].y - itemCorners[0].y;
        float aboveTop = itemCorners[1].y - viewCorners[1].y;

        float shift = 0f;
        if (belowBottom > 0f) shift = belowBottom;      // item hidden below: move content up
        else if (aboveTop > 0f) shift = -aboveTop;      // item hidden above: move content down
        if (shift == 0f) return;                        // guard clause: already visible

        gridScroll.StopMovement();
        gridScroll.content.position += new Vector3(0f, shift, 0f);
    }

    // Delete button: ask first.
    public void RequestDelete()
    {
        if (selected == null) return;               // guard clause
        confirmPanel.SetActive(true);
        EventSystem.current.SetSelectedGameObject(confirmNoButton.gameObject);  // safe default
    }

    // "Yes, delete" button.
    public void ConfirmDelete()
    {
        confirmPanel.SetActive(false);
        if (selected == null) return;               // guard clause
        journal.DeleteEntry(selected.Entry);        // raises JournalChanged, which rebuilds the grid
    }

    // "No, keep it" button.
    public void CancelDelete()
    {
        confirmPanel.SetActive(false);
        if (selected != null) EventSystem.current.SetSelectedGameObject(selected.gameObject);
    }
}
