Lesson 8 of 12 · 50 minutes

Platform services

Commercial games reward players with achievements and send their screenshots to the platform's library. But your school computer can't run Steam. Today you'll solve that the way professional studios do: write an interface that describes what a platform must do, then build a mock that does it on any computer. Next lesson, the real Steam version plugs into the same interface.

Producing & implementing
Last lesson: you refactored every control into one asset, making it the single source of truth, and proved nothing broke with regression testing. Today's achievement table is another single source of truth, and the interface is the strongest form of low coupling yet.

Teaching advice

Timing: recap and vocabulary 4 min · platform analysis 6 min · interface and table 8 min · pseudocode and code walkthrough 12 min · desk check and bug detective 5 min · setup and testing 10 min · checkpoint 5 min.

Key concept: an interface is new for most students. The power-socket analogy works well: a socket defines the shape of the plug, and any appliance that fits the shape works, whether it's a kettle or a lamp.

Testing tip: achievements unlock once and are remembered. To test again, right-click the MockPlatformService component's header in the Inspector and choose Reset mock achievements.

Learning intentions

By the end of this lesson I can:

  • explain an interface as a contract and implement one in C#
  • explain why a mock lets a team build and test without the real service
  • drive features from a data table instead of scattered code
  • use a queue to handle events in the order they happen.
Success criteria: my game shows an achievement pop-up the first time each achievement is earned, never twice, shows several in order if they unlock together, and logs every new photo as a platform screenshot, all without Steam.

Key vocabulary

Analysing

Same job, different platforms

Many games release on several platforms. Steam has achievements, Xbox has achievements, PlayStation has trophies. Each also has a screenshot library. They all do similar jobs, but each platform's code is completely different.

Analysis activity · pairs · 6 min

Find what's common

  1. A studio's game calls Steam's achievement code directly in 40 places. They now want to release on another platform. What do they have to do?
  2. List the jobs our photo journal needs a platform to do, ignoring how any one platform does them.
  3. Think about achievements you've enjoyed or disliked. Which kind suits a calm hiking game: "take 1000 photos" or "photograph three different places"? Why?
  1. Find and rewrite all 40, then keep two versions in step forever. Every bug fix has to be made twice.
  2. Check whether an achievement is unlocked, unlock an achievement, and add a screenshot. Those three jobs become our interface.
  3. Achievements that reward exploring suit a game with no pressure. "Grind" achievements push players to repeat actions, which works against the calm purpose from Lesson 1.
Planning

The contract

An interface lists those jobs as methods, with no code inside. It is a promise: any class that implements it must provide every method. Code that uses a platform only ever talks to the interface.

1IPlatformService.cs: the whole interface
// Recommended filename: IPlatformService.cs
// The contract: what any platform (Steam, a mock, a future console) must be able to do.
public interface IPlatformService
{
    string Name { get; }
    bool IsUnlocked(string achievementId);
    void UnlockAchievement(string achievementId);
    void AddScreenshot(string filePath, string locationName);
}
By convention, interface names start with I. Notice there are no curly braces and no code, just the shape of each method. Like a power socket, it defines what fits, not what the appliance does.

The achievement table

Each achievement needs an ID, a title, a description and, for Lesson 9, the matching ID in Valve's test app Spacewar. Rather than scattering these through the code, they live in one table: another single source of truth.

Our IDTitleHow to earn itSpacewar ID (Lesson 9)
FIRST_PHOTOSay CheeseTake your first photoACH_WIN_ONE_GAME
THREE_TRAILSTrail CollectorTake photos in 3 different placesACH_TRAVEL_FAR_ACCUM

Spacewar comes with its own fixed achievements, so ours borrow their IDs. A real release would have its own, and only the last column would change.

Pseudocode first

NSW pseudocode · CheckAchievements and CountPlaces

1   BEGIN CheckAchievements
2       IF number of entries >= 1 THEN
3           UnlockAchievement("FIRST_PHOTO")
4       ENDIF
5       IF CountPlaces() >= 3 THEN
6           UnlockAchievement("THREE_TRAILS")
7       ENDIF
8       IF journal is full THEN
9           UnlockAchievement("FULL_JOURNAL")
10      ENDIF
11  END CheckAchievements

12  BEGIN CountPlaces
13      SET places TO empty list
14      FOR EACH entry IN journal entries
15          IF entry.locationName NOT IN places THEN
16              ADD entry.locationName TO places
17          ENDIF
18      NEXT entry
19      RETURN length of places
20  END CountPlaces

NSW pseudocode · UnlockAchievement (mock) with a queue

1   BEGIN UnlockAchievement(id)
2       IF id is already unlocked THEN
3           RETURN
4       ENDIF
5       REMEMBER id as unlocked
6       ADD id TO BACK OF toastQueue
7       IF not showing toasts THEN
8           ShowToasts()
9       ENDIF
10  END UnlockAchievement

11  BEGIN ShowToasts
12      WHILE toastQueue is not empty
13          SET next TO REMOVE FROM FRONT OF toastQueue
14          SHOW pop-up for next
15          WAIT 3 seconds
16          HIDE pop-up
17      ENDWHILE
18  END ShowToasts
Producing

Into C#

2The mock keeps the promise
public class MockPlatformService : MonoBehaviour, IPlatformService

public void UnlockAchievement(string achievementId)
{
    if (IsUnlocked(achievementId)) return;              // guard clause: unlock once only

    AchievementInfo info = Achievements.Find(achievementId);
    if (info == null)                                   // guard clause: not in the table
    {
        Debug.LogWarning("Unknown achievement: " + achievementId);
        return;
    }

    PlayerPrefs.SetInt("mock_ach_" + achievementId, 1);
    PlayerPrefs.Save();

    toastQueue.Enqueue(info);                           // join the back of the queue
    if (!showingToasts) StartCoroutine(ShowToasts());
}

private IEnumerator ShowToasts()
{
    showingToasts = true;
    while (toastQueue.Count > 0)
    {
        AchievementInfo info = toastQueue.Dequeue();    // take from the front
        toastTitle.text = "Achievement unlocked: " + info.title;
        toastDescription.text = info.description;
        toastPanel.SetActive(true);
        yield return new WaitForSecondsRealtime(toastSeconds);
        toastPanel.SetActive(false);
        yield return new WaitForSecondsRealtime(0.3f);  // short gap between pop-ups
    }
    showingToasts = false;
}
, IPlatformService after MonoBehaviour is the promise. If the class left out any method from the interface, Unity would refuse to compile it. The mock remembers unlocks with PlayerPrefs, Unity's small built-in settings store, so they survive a restart just as real achievements do.
3One shared "current platform"
public static void Register(IPlatformService service)
{
    if (Current != null) return;        // guard clause: the first platform to register wins
    Current = service;
    Debug.Log("Platform services: " + service.Name);
}
Current has the type IPlatformService, the interface, not the mock. That's what lets the Steam version slot in next lesson. The first platform to register wins. In Lesson 9 the Steam version tries first, and the mock only steps in if Steam isn't running.
4PlatformLink: watching the journal
private void OnJournalChanged()
{
    if (Platform.Current == null) return;   // guard clause: no platform registered

    int count = journal.Entries.Count;
    if (count > lastCount)                  // a photo was added, not deleted
    {
        JournalEntry newest = journal.Entries[count - 1];
        string path = Path.Combine(journal.PhotoFolder, newest.fileName);
        Platform.Current.AddScreenshot(path, newest.locationName);
    }
    lastCount = count;
    CheckAchievements();
}

private void CheckAchievements()
{
    if (Platform.Current == null) return;   // guard clause

    if (journal.Entries.Count >= 1) Platform.Current.UnlockAchievement(Achievements.FirstPhoto);
    if (CountPlaces() >= placesNeeded) Platform.Current.UnlockAchievement(Achievements.ThreeTrails);
    if (journal.IsFull) Platform.Current.UnlockAchievement(Achievements.FullJournal);
}
Every line here calls Platform.Current, without knowing whether it's the mock or Steam. That's polymorphism. Comparing count with lastCount tells a new photo apart from a deletion, because JournalChanged fires for both.

Bug detective

"Say Cheese" after every single photo

A classmate's pop-up says "Achievement unlocked: Say Cheese" after their first photo, and their second, and their third. Here's their mock's UnlockAchievement:

public void UnlockAchievement(string achievementId)
{
    AchievementInfo info = Achievements.Find(achievementId);
    PlayerPrefs.SetInt("mock_ach_" + achievementId, 1);
    toastQueue.Enqueue(info);
    if (!showingToasts) StartCoroutine(ShowToasts());
}
The guard clause is missing. CheckAchievements runs after every journal change, and "at least 1 photo" is still true after photo 2, 3 and 4, so it asks to unlock FIRST_PHOTO every time. Without if (IsUnlocked(achievementId)) return; at the top, each request becomes a new pop-up. In our test run, 3 photos made 5 unlock requests but only 3 achievements, so the guard pattern blocked the 2 repeats.
Producing

Set it up

Setup · follow along · 8 min

  1. Create five scripts from the full listings below: IPlatformService, Platform, Achievements, MockPlatformService and PlatformLink.
  2. Create a canvas called ToastCanvas with a panel in a top corner holding two TMP texts: title and description. Give it a higher Sort Order than your other canvases so it appears on top.
  3. Add MockPlatformService to the PhotoMode object and drag in the panel and both texts.

// Recommended filename: Platform.cs
using UnityEngine;

// The one place every script asks for "the current platform".
public static class Platform
{
    public static IPlatformService Current { get; private set; }

    public static void Register(IPlatformService service)
    {
        if (Current != null) return;        // guard clause: the first platform to register wins
        Current = service;
        Debug.Log("Platform services: " + service.Name);
    }

    // Clears the old value each time Play is pressed, even if the Editor skips reloading scripts.
    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
    private static void ResetForPlayMode()
    {
        Current = null;
    }
}
// Recommended filename: Achievements.cs

// One row of the achievement table.
public class AchievementInfo
{
    public readonly string id;
    public readonly string title;
    public readonly string description;
    public readonly string spacewarId;      // used by the Steam version in Lesson 9

    public AchievementInfo(string id, string title, string description, string spacewarId)
    {
        this.id = id;
        this.title = title;
        this.description = description;
        this.spacewarId = spacewarId;
    }
}

// The achievement table: the single source of truth for every achievement.
public static class Achievements
{
    public const string FirstPhoto = "FIRST_PHOTO";
    public const string ThreeTrails = "THREE_TRAILS";
    public const string FullJournal = "FULL_JOURNAL";

    public static readonly AchievementInfo[] All =
    {
        new AchievementInfo(FirstPhoto,  "Say Cheese",        "Take your first photo",              "ACH_WIN_ONE_GAME"),
        new AchievementInfo(ThreeTrails, "Trail Collector",   "Take photos in 3 different places",  "ACH_TRAVEL_FAR_ACCUM"),
        new AchievementInfo(FullJournal, "Every Page Filled", "Fill your journal",                  "ACH_WIN_100_GAMES"),
    };

    // Linear search: check each row until the id matches.
    public static AchievementInfo Find(string id)
    {
        foreach (AchievementInfo info in All)
        {
            if (info.id == id) return info;
        }
        return null;
    }
}
// Recommended filename: MockPlatformService.cs
using System.Collections;
using System.Collections.Generic;
using System.IO;
using TMPro;
using UnityEngine;

[DefaultExecutionOrder(-50)]                // registers before other scripts start
public class MockPlatformService : MonoBehaviour, IPlatformService
{
    [Header("Achievement pop-up (on its own canvas)")]
    [SerializeField] private GameObject toastPanel;
    [SerializeField] private TMP_Text toastTitle;
    [SerializeField] private TMP_Text toastDescription;
    [SerializeField] private float toastSeconds = 3f;

    public string Name => "Mock (no Steam)";

    private readonly Queue<AchievementInfo> toastQueue = new Queue<AchievementInfo>();
    private bool showingToasts;

    private void Awake()
    {
        Platform.Register(this);
        toastPanel.SetActive(false);
    }

    public bool IsUnlocked(string achievementId)
    {
        return PlayerPrefs.GetInt("mock_ach_" + achievementId, 0) == 1;
    }

    public void UnlockAchievement(string achievementId)
    {
        if (IsUnlocked(achievementId)) return;              // guard clause: unlock once only

        AchievementInfo info = Achievements.Find(achievementId);
        if (info == null)                                   // guard clause: not in the table
        {
            Debug.LogWarning("Unknown achievement: " + achievementId);
            return;
        }

        PlayerPrefs.SetInt("mock_ach_" + achievementId, 1);
        PlayerPrefs.Save();

        toastQueue.Enqueue(info);                           // join the back of the queue
        if (!showingToasts) StartCoroutine(ShowToasts());
    }

    public void AddScreenshot(string filePath, string locationName)
    {
        Debug.Log("[Mock] Screenshot added: " + Path.GetFileName(filePath) + " at " + locationName);
    }

    private IEnumerator ShowToasts()
    {
        showingToasts = true;
        while (toastQueue.Count > 0)
        {
            AchievementInfo info = toastQueue.Dequeue();    // take from the front
            toastTitle.text = "Achievement unlocked: " + info.title;
            toastDescription.text = info.description;
            toastPanel.SetActive(true);
            yield return new WaitForSecondsRealtime(toastSeconds);
            toastPanel.SetActive(false);
            yield return new WaitForSecondsRealtime(0.3f);  // short gap between pop-ups
        }
        showingToasts = false;
    }

    // Right-click the component's title in the Inspector to test achievements again.
    [ContextMenu("Reset mock achievements")]
    private void ResetMockAchievements()
    {
        foreach (AchievementInfo info in Achievements.All)
        {
            PlayerPrefs.DeleteKey("mock_ach_" + info.id);
        }
        Debug.Log("[Mock] Achievements reset.");
    }
}
// Recommended filename: PlatformLink.cs
using System.Collections.Generic;
using System.IO;
using UnityEngine;

// Connects the journal to whichever platform is running. It never needs to know which one.
public class PlatformLink : MonoBehaviour
{
    [SerializeField] private Journal journal;
    [SerializeField] private int placesNeeded = 3;

    private int lastCount;

    private void Start()
    {
        lastCount = journal.Entries.Count;
        journal.JournalChanged += OnJournalChanged;
        CheckAchievements();                    // counts progress made before achievements existed
    }

    private void OnDestroy()
    {
        journal.JournalChanged -= OnJournalChanged;
    }

    private void OnJournalChanged()
    {
        if (Platform.Current == null) return;   // guard clause: no platform registered

        int count = journal.Entries.Count;
        if (count > lastCount)                  // a photo was added, not deleted
        {
            JournalEntry newest = journal.Entries[count - 1];
            string path = Path.Combine(journal.PhotoFolder, newest.fileName);
            Platform.Current.AddScreenshot(path, newest.locationName);
        }
        lastCount = count;
        CheckAchievements();
    }

    private void CheckAchievements()
    {
        if (Platform.Current == null) return;   // guard clause

        if (journal.Entries.Count >= 1) Platform.Current.UnlockAchievement(Achievements.FirstPhoto);
        if (CountPlaces() >= placesNeeded) Platform.Current.UnlockAchievement(Achievements.ThreeTrails);
        if (journal.IsFull) Platform.Current.UnlockAchievement(Achievements.FullJournal);
    }

    // Counts how many different location names appear in the journal.
    private int CountPlaces()
    {
        List<string> places = new List<string>();
        foreach (JournalEntry entry in journal.Entries)
        {
            if (!places.Contains(entry.locationName))
            {
                places.Add(entry.locationName);
            }
        }
        return places.Count;
    }
}

Why ResetForPlayMode?

Static values can survive between presses of Play if the Editor is set to skip reloading scripts. Without the reset, Platform.Current could point to a mock from your last test that no longer exists.
