Steamworks in practice

Last lesson's interface was a promise. Today you'll read the real Steam version that keeps it: the code that unlocks achievements on Steam, sends photos to the Steam screenshot library and opens Steam Deck's on-screen keyboard. Steam can't run at school, so you'll learn it the way developers learn any unfamiliar code: by reading the documentation and tracing. Then you'll use it to add the last missing feature, captions.

Learning intentions

By the end of this lesson I can:

  • read API documentation and use it to trace unfamiliar code
  • explain how a game falls back to a mock when a service isn't available
  • explain why changing an interface affects every class that implements it
  • add a text-entry feature that works with a keyboard or Steam Deck's on-screen keyboard.
Success criteria: my project compiles with the Steam version included, I can explain what each Steam call does, and players can add, change and keep captions of up to 60 characters.

Key vocabulary

Analysing

Why is Steamworks free?

Case study · enterprise

A platform is a business

Valve gives developers the Steamworks SDK, a free test app called Spacewar and documentation, at no cost. A volunteer project, Steamworks.NET, wraps the SDK so Unity developers can use it from C#. Valve earns money by taking a share of each game sold on Steam, typically 30%.

Features like achievements, screenshot libraries and Steam Deck support keep players coming back to Steam and make it more attractive than other stores. The easier Valve makes it to add these features, the more games use them, and the more valuable Steam becomes for everyone.

Discuss: Who benefits when a small studio adds Steam achievements to its game: the studio, the players, Valve, or all three? Is there anyone it could disadvantage?

Researching

Read the documentation

Professional developers rarely memorise an API. They read its reference. Here are the five Steam calls our code uses, summarised in plain English from the Steamworks documentation.

CallWhat it doesReturns
SteamAPI.Init()Connects the game to the running Steam client. Must succeed before any other Steam call.true if connected, false if not (e.g. Steam isn't running)
SteamUserStats.SetAchievement(name)Marks an achievement as unlocked on this computer only. Nothing is sent to Steam yet.true if the name exists
SteamUserStats.StoreStats()Uploads changed stats and achievements to Steam's servers. This is what makes Steam show its own unlock pop-up.true if the upload was started
SteamScreenshots.AddScreenshotToLibrary(file, thumbnail, width, height)Copies an image file into the player's Steam screenshot library. Pass null as the thumbnail and Steam makes one.A handle that identifies the new screenshot
SteamUtils.ShowFloatingGamepadTextInput(mode, x, y, width, height)On Steam Deck, opens the on-screen keyboard positioned so it doesn't cover the text box. Typed letters arrive as normal key presses.true if the keyboard was shown

DART · reading for detail · pairs · 5 min

Use only the table above to answer:

  1. A developer calls SetAchievement but forgets StoreStats. What does the player see on Steam?
  2. What should the game do if SteamAPI.Init() returns false?
  3. The table says typed letters "arrive as normal key presses". Why might that cause a problem in a game that uses letter keys as controls?
  1. Nothing. The unlock exists only locally and never reaches Steam's servers, so there's no pop-up and nothing on their profile.
  2. Make no other Steam calls, and fall back to something else, which for us is the mock.
  3. Typing a caption containing "j" would also trigger our ToggleJournal control. Hold that thought until the bug detective.

Who registers first?

Both platform services exist in the scene. [DefaultExecutionOrder] makes the Steam version's Awake run first (−100), then the mock's (−50). Remember that Platform.Register keeps whichever registers first.

NSW pseudocode · SteamPlatformService.Awake

1   BEGIN Awake
2       TRY
3           SET initialised TO SteamAPI.Init()
4       CATCH Steam library missing
5           SET initialised TO FALSE
6       ENDTRY
7       IF initialised = FALSE THEN
8           DISPLAY "Steam not available, so the mock will be used."
9           RETURN
10      ENDIF
11      Platform.Register(this)
12  END Awake
SituationSteam Awake (−100)Mock Awake (−50)Platform.Current
School PC, no Steamworks.NETFile skipped by #if, so it never runsRegistersMock
Steamworks.NET installed, Steam closedInit → false, guard clause returnsRegistersMock
Steam running (PC or Steam Deck)Init → true, registersRegister ignored (already set)Steam

In every situation the game works, and no other script needs to know which row it's in. This is the payoff of designing the interface first.

public void UnlockAchievement(string achievementId)
{

Compare this with the mock's version: same guard clause, same table lookup, different final two lines. info.spacewarId turns our FIRST_PHOTO into Spacewar's ACH_WIN_ONE_GAME. A real release would only change the table.

4The on-screen keyboard
public bool ShowOnScreenKeyboard(Rect screenArea)
{
    if (!SteamUtils.IsSteamRunningOnSteamDeck()) return false;   // guard clause: PCs have keyboards

    // Unity measures y from the bottom of the screen; Steam measures from the top.
    int topY = Screen.height - (int)(screenArea.y + screenArea.height);
    return SteamUtils.ShowFloatingGamepadTextInput(
        EFloatingGamepadTextInputMode.k_EFloatingGamepadTextInputModeModeSingleLine,
        (int)screenArea.x, topY, (int)screenArea.width, (int)screenArea.height);
}
Unity measures y from the bottom of the screen, but Steam measures from the top, so the code converts. On a 1280 × 800 screen, a text box starting 300 px from the bottom and 60 px tall has its top edge at 800 − (300 + 60) = 440 px from the top. We ran this calculation to check it.

Changing the contract

Captions need a keyboard on Steam Deck, so IPlatformService gets a fourth method. Watch what happens the moment it's added:

IPlatformService.cs: ADD ONE LINE
bool ShowOnScreenKeyboard(UnityEngine.Rect screenArea);   // added in Lesson 9

Unity immediately refuses to compile. This is the error we got when we tried it:

error CS0535: 'MockPlatformService' does not implement interface member
'IPlatformService.ShowOnScreenKeyboard(UnityEngine.Rect)'

The compiler is enforcing the promise: MockPlatformService said it implements IPlatformService, and now it doesn't. This is a breaking change. Every class that implements the interface must change too, which is why interfaces should be designed carefully and changed rarely. The fix is to keep the promise:

5MockPlatformService.cs: the new method
// A PC player has a real keyboard, so the mock never needs to show one.
public bool ShowOnScreenKeyboard(Rect screenArea)
{
    Debug.Log("[Mock] On-screen keyboard not needed on this computer.");
    return false;
}
Returning false means "no keyboard was shown", which is true on a PC. The mock doesn't have to do anything clever. It just has to keep the promise honestly.

Your Lesson 2 storyboard had a Caption button and your data dictionary limited captions to 60 characters. Both now get built.

1   BEGIN OpenCaption

3       IF editing = nothing THEN
4           RETURN
5       ENDIF
6       DISABLE journal controls
7       SHOW caption box WITH editing.caption
8       Platform.ShowOnScreenKeyboard(caption box area)
9   END OpenCaption

10  BEGIN SetCaption(entry, text)
11      SET text TO text WITHOUT spaces at either end
12      IF length of text > 60 THEN
13          SET text TO first 60 characters of text
14      ENDIF
15      SET entry.caption TO text
16      Save()
17  END SetCaption
6Journal.cs: SetCaption
ADD TO Journal
public void SetCaption(JournalEntry entry, string caption)
{
    if (!data.entries.Contains(entry)) return;      // guard clause

    caption = (caption ?? "").Trim();
    if (caption.Length > MaxCaptionLength)          // enforce the data dictionary rule
    {
        caption = caption.Substring(0, MaxCaptionLength);
    }
    entry.caption = caption;
    Save();
    JournalChanged?.Invoke();
}
The input box already stops at 60 characters, so why check again? Because the journal can't trust that every caller used that box. Validating where data is stored protects it from every path. We tested it with a 70-character caption (cut to 60) and a caption with spaces around it (trimmed).

Bug detective

"Journey home" closes the journal

A classmate's caption box works until they type a word with a "j" in it, like "journey". Then the journal snaps shut and the caption is lost. Here's their Open:

public void Open()
{
    editing = journalScreen.SelectedEntry;
    if (editing == null) return;
    captionPanel.SetActive(true);
    inputField.text = editing.caption;
    inputField.ActivateInputField();
}
The journal's controls are still switched on. J is bound to ToggleJournal, so typing "j" in the caption is also a press of the journal button. The fix is journalScreen.enabled = false; while typing, and back to true when the box closes. Disabling the script runs its OnDisable, which disables its input actions. On Steam Deck this matters too: the on-screen keyboard sends letters as normal key presses.

// Only compiles when Steamworks.NET is installed. Without it, this whole file is skipped
// and the mock takes over, so the project still builds on computers without Steam.
#if STEAMWORKS_NET && !DISABLESTEAMWORKS
using System;
using Steamworks;
using UnityEngine;

[DefaultExecutionOrder(-100)]                   // tries before the mock (-50)
public class SteamPlatformService : MonoBehaviour, IPlatformService
{
    public string Name => "Steam (App ID 480)";

    private bool initialised;

    private void Awake()
    {
        try
        {
            initialised = SteamAPI.Init();      // false if the Steam client isn't running
        }
        catch (DllNotFoundException)
        {
            initialised = false;                // Steam's library file is missing
        }

        if (!initialised)                       // guard clause: leave it to the mock
        {
            Debug.Log("Steam not available, so the mock will be used.");
            enabled = false;
            return;
        }
        Platform.Register(this);
    }

    private void Update()
    {
        SteamAPI.RunCallbacks();                // lets Steam deliver its messages each frame
    }

    private void OnApplicationQuit()
    {
        if (initialised) SteamAPI.Shutdown();
    }

    public bool IsUnlocked(string achievementId)
    {
        AchievementInfo info = Achievements.Find(achievementId);
        if (info == null) return false;         // guard clause: not in the table

        SteamUserStats.GetAchievement(info.spacewarId, out bool achieved);
        return achieved;
    }

    public void UnlockAchievement(string achievementId)
    {
        if (IsUnlocked(achievementId)) return;  // guard clause: unlock once only

        AchievementInfo info = Achievements.Find(achievementId);
        if (info == null) return;               // guard clause

        SteamUserStats.SetAchievement(info.spacewarId);     // Steam's name comes from the table
        SteamUserStats.StoreStats();                        // upload it, and show Steam's pop-up
    }

    public void AddScreenshot(string filePath, string locationName)
    {
        // null thumbnail: Steam makes its own. The size is the screen the photo was taken from.
        ScreenshotHandle handle = SteamScreenshots.AddScreenshotToLibrary(filePath, null, Screen.width, Screen.height);
        SteamScreenshots.SetLocation(handle, locationName);
    }

    public bool ShowOnScreenKeyboard(Rect screenArea)
    {
        if (!SteamUtils.IsSteamRunningOnSteamDeck()) return false;   // guard clause: PCs have keyboards

        // Unity measures y from the bottom of the screen; Steam measures from the top.
        int topY = Screen.height - (int)(screenArea.y + screenArea.height);
        return SteamUtils.ShowFloatingGamepadTextInput(
            EFloatingGamepadTextInputMode.k_EFloatingGamepadTextInputModeModeSingleLine,
            (int)screenArea.x, topY, (int)screenArea.width, (int)screenArea.height);
    }
}

public class CaptionEditor : MonoBehaviour

        if (editing == null) return;                // guard clause: no photo selected

        captionPanel.SetActive(true);
        inputField.text = editing.caption;
        inputField.Select();
        inputField.ActivateInputField();

        RectTransform field = (RectTransform)inputField.transform;
        Platform.Current?.ShowOnScreenKeyboard(ScreenRect(field));
    }

    private void Save(string text)
    {
        if (editing == null) return;                // guard clause: already closed
        JournalEntry entry = editing;
        Close();
        journal.SetCaption(entry, text);            // JournalScreen is listening again by now
    }

    private void OnEndEdit(string text)
    {
        if (editing == null) return;                // guard clause: Save already ran
        Close();                                    // ended without submitting: cancel
    }

    private void Close()
    {
        editing = null;
        captionPanel.SetActive(false);
        journalScreen.enabled = true;
    }

    // For a Screen Space - Overlay canvas, world corners are screen pixels.
    private static Rect ScreenRect(RectTransform rect)
    {
        Vector3[] corners = new Vector3[4];         // 0 = bottom-left, 2 = top-right
        rect.GetWorldCorners(corners);
        return new Rect(corners[0].x, corners[0].y, corners[2].x - corners[0].x, corners[2].y - corners[0].y);
    }
}
// Recommended filename: Journal.cs
using System;
using System.Collections.Generic;
using System.Globalization;
using System.IO;
using UnityEngine;

[Serializable]
public class JournalEntry
{
    public string fileName;
    public string caption;
    public string locationName;
    public string timestamp;
}

// JsonUtility can't save a List on its own, so it goes inside a wrapper class.
[Serializable]
public class JournalData
{
    public List<JournalEntry> entries = new List<JournalEntry>();
}

public class Journal : MonoBehaviour
{
    [SerializeField] private PhotoCapture photoCapture;
    [SerializeField] private int maxPhotos = 50;

    public const int MaxCaptionLength = 60;     // from the Lesson 2 data dictionary

    // Lesson 6's journal screen listens for this.
    public event Action JournalChanged;

    public IReadOnlyList<JournalEntry> Entries => data.entries;
    public bool IsFull => data.entries.Count >= maxPhotos;
    public string PhotoFolder => photoFolder;

    private JournalData data = new JournalData();
    private string currentLocation = "Unknown trail";
    private string photoFolder;
    private string savePath;
    private string tempPath;

    private void Awake()
    {
        photoFolder = Path.Combine(Application.persistentDataPath, "Journal");
        Directory.CreateDirectory(photoFolder);
        savePath = Path.Combine(photoFolder, "journal.json");
        tempPath = savePath + ".tmp";
        Load();
    }

    private void OnEnable()
    {
        photoCapture.PhotoSaved += OnPhotoSaved;
    }

    private void OnDisable()
    {
        photoCapture.PhotoSaved -= OnPhotoSaved;
    }

    // A second hook: location zones in your world call this.
    public void SetLocation(string locationName)
    {
        currentLocation = locationName;
    }

    private void OnPhotoSaved(string fileName)
    {
        JournalEntry entry = new JournalEntry
        {
            fileName = fileName,
            caption = "",
            locationName = currentLocation,
            timestamp = DateTime.Now.ToString("yyyy-MM-ddTHH:mm:ss", CultureInfo.InvariantCulture)
        };
        data.entries.Add(entry);
        Save();
        JournalChanged?.Invoke();
    }

    public void SetCaption(JournalEntry entry, string caption)
    {
        if (!data.entries.Contains(entry)) return;      // guard clause

        caption = (caption ?? "").Trim();
        if (caption.Length > MaxCaptionLength)          // enforce the data dictionary rule
        {
            caption = caption.Substring(0, MaxCaptionLength);
        }
        entry.caption = caption;
        Save();
        JournalChanged?.Invoke();
    }

    public void DeleteEntry(JournalEntry entry)
    {
        if (!data.entries.Contains(entry)) return;      // guard clause

        string photoPath = Path.Combine(photoFolder, entry.fileName);
        if (File.Exists(photoPath)) File.Delete(photoPath);
        data.entries.Remove(entry);
        Save();
        JournalChanged?.Invoke();
    }

    private void Save()
    {
        string json = JsonUtility.ToJson(data, true);
        File.WriteAllText(tempPath, json);                  // 1. write the new version beside the old one
        if (File.Exists(savePath)) File.Delete(savePath);   // 2. remove the old version
        File.Move(tempPath, savePath);                      // 3. rename the new version into place
    }

    private void Load()
    {
        string path = savePath;
        if (!File.Exists(path))
        {
            if (!File.Exists(tempPath)) return;     // guard clause: first time playing
            path = tempPath;                        // recover from an interrupted save
        }

        try
        {
            data = JsonUtility.FromJson<JournalData>(File.ReadAllText(path)) ?? new JournalData();
        }
        catch (ArgumentException)
        {
            Debug.LogWarning("journal.json was damaged, so the journal is starting empty.");
            data = new JournalData();
            return;
        }

        RemoveMissingPhotos();
        Save();                                     // tidy up: one clean, valid save file
    }

    private void RemoveMissingPhotos()
    {
        for (int i = data.entries.Count - 1; i >= 0; i--)   // count backwards when removing
        {
            string photoPath = Path.Combine(photoFolder, data.entries[i].fileName);
            if (!File.Exists(photoPath))
            {
                data.entries.RemoveAt(i);
            }
        }
    }
}

using System;
using System.Collections;
using System.Collections.Generic;
using System.Globalization;
using System.IO;
using TMPro;
using UnityEngine;
using UnityEngine.EventSystems;
using UnityEngine.InputSystem;
using UnityEngine.UI;

public class JournalScreen : MonoBehaviour
{
    [Header("Input (from the PhotoJournalControls asset)")]
    [SerializeField] private InputActionReference toggleAction;
    [SerializeField] private InputActionReference backAction;

    [Header("Data and game")]
    [SerializeField] private Journal journal;
    [SerializeField] private PhotoModeController photoMode;
    [SerializeField] private Behaviour[] disableWhileOpen;  // movement, camera, PhotoModeController, PhotoCapture

    [Header("Grid")]
    [SerializeField] private GameObject screenRoot;         // the journal canvas
    [SerializeField] private ScrollRect gridScroll;         // set Movement Type to Clamped
    [SerializeField] private Transform gridContent;         // ScrollRect content with a GridLayoutGroup
    [SerializeField] private JournalThumbnail thumbnailPrefab;
    [SerializeField] private GameObject emptyMessage;
    [SerializeField] private TMP_Text countText;
    [SerializeField] private int thumbnailWidth = 480;
    [SerializeField] private int thumbnailHeight = 270;

    [Header("Detail panel")]
    [SerializeField] private RawImage detailImage;
    [SerializeField] private TMP_Text captionText;
    [SerializeField] private TMP_Text locationText;
    [SerializeField] private TMP_Text dateText;

    [Header("Delete confirmation")]
    [SerializeField] private GameObject confirmPanel;
    [SerializeField] private Button confirmNoButton;

    public bool IsOpen { get; private set; }
    public JournalEntry SelectedEntry => selected != null ? selected.Entry : null;

    private readonly List<JournalThumbnail> thumbnails = new List<JournalThumbnail>();
    private JournalThumbnail selected;
    private float savedTimeScale = 1f;

    private void OnEnable()
    {
        toggleAction.action.performed += OnToggle;
        backAction.action.performed += OnBack;
        toggleAction.action.Enable();
        backAction.action.Enable();
        journal.JournalChanged += OnJournalChanged;
    }

    private void OnDisable()
    {
        toggleAction.action.performed -= OnToggle;
        backAction.action.performed -= OnBack;
        toggleAction.action.Disable();
        backAction.action.Disable();
        journal.JournalChanged -= OnJournalChanged;
    }

    private void OnToggle(InputAction.CallbackContext context)
    {
        if (IsOpen) Close();
        else Open();
    }

    private void OnBack(InputAction.CallbackContext context)
    {
        if (!IsOpen) return;                        // guard clause: nothing to go back from
        if (confirmPanel.activeSelf) CancelDelete(); // back out of the question first
        else Close();
    }

    private void Open()
    {
        if (photoMode != null && photoMode.IsActive) return;   // guard clause: finish photo mode first

        IsOpen = true;
        foreach (Behaviour script in disableWhileOpen)
        {
            script.enabled = false;
        }
        savedTimeScale = Time.timeScale;
        Time.timeScale = 0f;

        screenRoot.SetActive(true);
        confirmPanel.SetActive(false);
        StartCoroutine(BuildGrid());
    }

    private void Close()
    {
        StopAllCoroutines();
        ClearGrid();
        screenRoot.SetActive(false);

        Time.timeScale = savedTimeScale;
        foreach (Behaviour script in disableWhileOpen)
        {
            script.enabled = true;
        }
        IsOpen = false;
    }

    private void OnJournalChanged()
    {
        if (!IsOpen) return;                        // guard clause
        StopAllCoroutines();
        StartCoroutine(BuildGrid());
    }

    private IEnumerator BuildGrid()
    {
        JournalEntry keep = SelectedEntry;          // remember the selection across a rebuild
        ClearGrid();

        int count = journal.Entries.Count;
        countText.text = count == 1 ? "1 photo" : count + " photos";
        emptyMessage.SetActive(count == 0);
        if (count == 0)
        {
            ShowDetail(null);
            yield break;
        }

        // 1. Make every button now, newest first, so the layout appears at once.
        for (int i = count - 1; i >= 0; i--)
        {
            JournalThumbnail thumb = Instantiate(thumbnailPrefab, gridContent);
            thumb.Setup(journal.Entries[i], this);
            thumbnails.Add(thumb);
        }
        JournalThumbnail first = thumbnails[0];
        foreach (JournalThumbnail thumb in thumbnails)
        {
            if (thumb.Entry == keep) first = thumb;     // same photo as before, if it still exists
        }
        EventSystem.current.SetSelectedGameObject(first.gameObject);

        // 2. Load one photo per frame, so the screen never freezes.
        foreach (JournalThumbnail thumb in thumbnails)
        {
            thumb.SetTexture(LoadThumbnail(thumb.Entry));
            if (thumb == selected) detailImage.texture = thumb.Texture;
            yield return null;
        }
    }

    private void ClearGrid()
    {
        foreach (JournalThumbnail thumb in thumbnails)
        {
            if (thumb.Texture != null) Destroy(thumb.Texture);   // free its memory
            Destroy(thumb.gameObject);
        }
        thumbnails.Clear();
        selected = null;
        detailImage.texture = null;
    }

    private Texture2D LoadThumbnail(JournalEntry entry)
    {
        string path = Path.Combine(journal.PhotoFolder, entry.fileName);
        if (!File.Exists(path)) return null;        // guard clause

        Texture2D full = new Texture2D(2, 2);
        full.LoadImage(File.ReadAllBytes(path));    // decodes the PNG and resizes to fit
        Texture2D thumb = Shrink(full, thumbnailWidth, thumbnailHeight);
        Destroy(full);                              // keep only the small copy
        return thumb;
    }

    private static Texture2D Shrink(Texture2D source, int width, int height)
    {
        RenderTexture temp = RenderTexture.GetTemporary(width, height);
        Graphics.Blit(source, temp);                // GPU draws the photo at the new size

        RenderTexture previous = RenderTexture.active;
        RenderTexture.active = temp;
        Texture2D small = new Texture2D(width, height, TextureFormat.RGB24, false);
        small.ReadPixels(new Rect(0, 0, width, height), 0, 0);
        small.Apply();

        RenderTexture.active = previous;
        RenderTexture.ReleaseTemporary(temp);
        return small;
    }

    public void ShowDetail(JournalThumbnail thumb)
    {
        selected = thumb;
        if (thumb == null)
        {
            detailImage.texture = null;
            captionText.text = "";
            locationText.text = "";
            dateText.text = "";
            return;
        }

        JournalEntry entry = thumb.Entry;
        detailImage.texture = thumb.Texture;
        captionText.text = string.IsNullOrEmpty(entry.caption) ? "No caption yet" : entry.caption;
        locationText.text = entry.locationName;

        // Saved in one fixed format, shown in the player's own format.
        if (DateTime.TryParseExact(entry.timestamp, "yyyy-MM-ddTHH:mm:ss",
                CultureInfo.InvariantCulture, DateTimeStyles.None, out DateTime taken))
        {
            dateText.text = taken.ToString("g", CultureInfo.CurrentCulture);   // e.g. 2/10/2026 2:30 PM in Australia
        }
        else
        {
            dateText.text = "Unknown date";
        }
    }

    // Scrolls the grid just enough to keep a selected thumbnail on screen.
    public void KeepVisible(RectTransform item)
    {
        Vector3[] itemCorners = new Vector3[4];     // 0 = bottom-left, 1 = top-left
        Vector3[] viewCorners = new Vector3[4];
        item.GetWorldCorners(itemCorners);
        gridScroll.viewport.GetWorldCorners(viewCorners);

        float belowBottom = viewCorners[0].y - itemCorners[0].y;
        float aboveTop = itemCorners[1].y - viewCorners[1].y;

        float shift = 0f;
        if (belowBottom > 0f) shift = belowBottom;      // item hidden below: move content up
        else if (aboveTop > 0f) shift = -aboveTop;      // item hidden above: move content down
        if (shift == 0f) return;                        // guard clause: already visible

        gridScroll.StopMovement();
        gridScroll.content.position += new Vector3(0f, shift, 0f);
    }

    // Delete button: ask first.
    public void RequestDelete()
    {
        if (selected == null) return;               // guard clause
        confirmPanel.SetActive(true);
        EventSystem.current.SetSelectedGameObject(confirmNoButton.gameObject);  // safe default
    }

    // "Yes, delete" button.
    public void ConfirmDelete()
    {
        confirmPanel.SetActive(false);
        if (selected == null) return;               // guard clause
        journal.DeleteEntry(selected.Entry);        // raises JournalChanged, which rebuilds the grid
    }

    // "No, keep it" button.
    public void CancelDelete()
    {
        confirmPanel.SetActive(false);
        if (selected != null) EventSystem.current.SetSelectedGameObject(selected.gameObject);
    }
}

// Recommended filename: MockPlatformService.cs
using System.Collections;
using System.Collections.Generic;
using System.IO;
using TMPro;
using UnityEngine;

[DefaultExecutionOrder(-50)]                // registers before other scripts start
public class MockPlatformService : MonoBehaviour, IPlatformService
{
    [Header("Achievement pop-up (on its own canvas)")]
    [SerializeField] private GameObject toastPanel;
    [SerializeField] private TMP_Text toastTitle;
    [SerializeField] private TMP_Text toastDescription;
    [SerializeField] private float toastSeconds = 3f;

    public string Name => "Mock (no Steam)";

    private readonly Queue<AchievementInfo> toastQueue = new Queue<AchievementInfo>();
    private bool showingToasts;

    private void Awake()
    {
        Platform.Register(this);
        toastPanel.SetActive(false);
    }

    public bool IsUnlocked(string achievementId)
    {
        return PlayerPrefs.GetInt("mock_ach_" + achievementId, 0) == 1;
    }

    public void UnlockAchievement(string achievementId)
    {
        if (IsUnlocked(achievementId)) return;              // guard clause: unlock once only

        AchievementInfo info = Achievements.Find(achievementId);
        if (info == null)                                   // guard clause: not in the table
        {
            Debug.LogWarning("Unknown achievement: " + achievementId);
            return;
        }

        PlayerPrefs.SetInt("mock_ach_" + achievementId, 1);
        PlayerPrefs.Save();

        toastQueue.Enqueue(info);                           // join the back of the queue
        if (!showingToasts) StartCoroutine(ShowToasts());
    }

    public void AddScreenshot(string filePath, string locationName)
    {
        Debug.Log("[Mock] Screenshot added: " + Path.GetFileName(filePath) + " at " + locationName);
    }

    // A PC player has a real keyboard, so the mock never needs to show one.
    public bool ShowOnScreenKeyboard(Rect screenArea)
    {
        Debug.Log("[Mock] On-screen keyboard not needed on this computer.");
        return false;
    }

    private IEnumerator ShowToasts()
    {
        showingToasts = true;
        while (toastQueue.Count > 0)
        {
            AchievementInfo info = toastQueue.Dequeue();    // take from the front
            toastTitle.text = "Achievement unlocked: " + info.title;
            toastDescription.text = info.description;
            toastPanel.SetActive(true);
            yield return new WaitForSecondsRealtime(toastSeconds);
            toastPanel.SetActive(false);
            yield return new WaitForSecondsRealtime(0.3f);  // short gap between pop-ups
        }
        showingToasts = false;
    }

    // Right-click the component's title in the Inspector to test achievements again.
    [ContextMenu("Reset mock achievements")]
    private void ResetMockAchievements()
    {
        foreach (AchievementInfo info in Achievements.All)
        {
            PlayerPrefs.DeleteKey("mock_ach_" + info.id);
        }
        Debug.Log("[Mock] Achievements reset.");
    }
}
