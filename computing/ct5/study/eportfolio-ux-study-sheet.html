E-Portfolio UX — Study Sheet

Every question, answer and explanation from the E-Portfolio UX Topic Review Notebook — 96 questions across all four Design & Production Framework phases. Use this to check your work, revise before a test, or as a printable reference. It won't update automatically if the notebook changes — always check against the notebook itself if in doubt.

1. Identifying and Defining

Foundation (D–E) (8 questions)

Q1 Multiple choice

A student's Game Design e-portfolio has a clean layout, working links, and clear labels on every page. What is this mostly an example of?

Answer: Good user experience (UX) design

Correct — UX is about how it feels and works to use, which is exactly what a clean layout and clear labels support.

Q2 Multiple choice

A visitor types feedback into the survey on a student's portfolio and clicks 'submit'. What is this an example of?

Answer: An input

Correct — the visitor entering feedback is data going into the system.

Q3 Multiple choice

"The portfolio site must let a visitor click a project thumbnail and see the full project page." This is an example of a:

Answer: Functional requirement

Correct — it describes something the system must do.

Q4 Multiple choice

"The portfolio's pages should load in under 3 seconds on a school laptop." This is an example of a:

Answer: Non-functional requirement

Correct — it describes a quality (speed) rather than a specific action the site must perform.

Q5 Multiple choice

A student includes a playtester's full name and email address next to a negative comment on their public portfolio, without asking. This mainly raises a concern about:

Answer: Ethical and privacy responsibility

Correct — publishing someone's personal details without consent is an ethical and privacy issue.

Q6 Multiple choice

A 'terms of use' policy on a website mainly exists to:

Answer: Set out the rules and responsibilities for using the site and its data

Correct — terms of use explain what users can and can't do, and how their data may be used.

Q7 Multiple choice

A student adds alt text to every image and captions to their embedded gameplay video. This best supports:

Answer: A more diverse audience being able to access the content

Correct — alt text and captions help people with different needs (e.g. vision or hearing) access the same content.

Q8 Multiple choice

A student saves their game screenshots as a highly compressed JPEG so the portfolio page loads quickly, even though the image looks very slightly blurrier. This is an example of:

Answer: Lossy compression

Correct — some image quality is permanently lost to achieve a smaller file size.

Core (C) (9 questions)

Q1 Multiple choice

Two portfolio sites show the exact same project information. Site A is confusing to navigate; Site B is clear and intuitive. What does this difference in UX mostly affect?

Answer: How successfully the visitor can find and understand the information

Correct — UX is about how effectively and comfortably a person can use the interface, not just what information is present.

Q2 Multiple choice

A visitor submits the playtest survey. Their answers are saved to a spreadsheet, and later a summary chart is shown on the student's reflections page. Which sequence correctly matches input → process → output?

Answer: Survey answer entered → data saved/summarised → chart displayed

Correct — this follows data from entry, through processing, to a visible result.

Q3 Multiple choice

A student embeds a playtest video of a peer without asking permission first. Which responsibility is most directly at risk?

Answer: Ethical responsibility around consent and use of someone else's content

Correct — using someone's image/likeness without consent is primarily an ethical and, potentially, legal issue.

Q4 Multiple choice

A student notices a free web-hosting platform's terms of use state that any content uploaded becomes reusable by the platform for its own promotional material. What is the most likely effect on how students use that platform?

Answer: Students may think twice about what personal or original content they upload

Correct — understanding the terms of use should influence what a user is comfortable sharing.

Q5 Multiple choice

A student's portfolio is written entirely in complex technical jargon with small, low-contrast text. Which group is this most likely to disadvantage?

Answer: A broad range of visitors, including those with vision differences or limited technical background

Correct — dense jargon and poor contrast create barriers for multiple types of users, not just one narrow group.

Q6 Multiple choice

A student is choosing how to export their Unity WebGL build for embedding via a link on their portfolio. Why does file compression matter here specifically?

Answer: Smaller files reduce loading time for visitors playing the embedded build

Correct — WebGL builds are downloaded by the browser, so smaller compressed files load and start faster.

Q7 Type-in

A written statement describing exactly what inputs a feature should accept and what output it should produce, used to check the feature works correctly, is called a ___.

Answer: test case

Accepted answer(s): test case, test cases

Q8 Type-in

Designing content so it can be used and understood by people with a wide range of needs and abilities is called ___ design.

Answer: inclusive

Accepted answer(s): inclusive, accessible, accessibility

Q9 Type-in

A compression method that permanently discards some data to make a file smaller, meaning the file can't be restored to its exact original, is called ___ compression.

Answer: lossy

Accepted answer(s): lossy

Extension (B–A) (7 questions)

Q1 Multiple choice

Two portfolio sites meet all the same functional requirements (all links work, all pages exist), but visitors describe one as "confusing" and the other as "a pleasure to use." What does this best show?

Answer: Meeting functional requirements alone doesn't guarantee a good user experience

Correct — UX depends heavily on non-functional qualities like clarity and ease of use, not just whether features technically work.

Q2 Multiple choice

A student's WebGL game build downloads slowly for playtesters on school wifi. Which change addresses the underlying input/output problem most directly?

Answer: Compressing the exported build so less data needs to transmit before the game can run

Correct — this reduces the amount of data that has to be transmitted (an input/output and transmission issue) before the visitor can interact with the game.

Q3 Multiple choice

A student is comparing two free hosting platforms' terms of use before choosing one for their portfolio. Platform A states uploaded content stays owned by the creator; Platform B states uploaded content becomes reusable by the platform. What is the most reasonable conclusion?

Answer: Platform A gives the student stronger control over their own original work

Correct — Platform A's terms explicitly protect the creator's ownership, which is a meaningful difference for someone sharing original game design work.

Q4 Multiple choice

A student's portfolio includes playtest quotes from peers, translated into casual slang that some cultural and language groups may not understand, with no alternative phrasing. This is most accurately described as a problem with:

Answer: Both inclusive communication and fair representation of a diverse audience

Correct — this affects how accessible and fairly representative the communication is across different audiences, touching both ideas at once.

Q5 Type-in

Providing more than one way to access the same content (e.g. captions as well as audio, or plain-language summaries as well as technical detail) so different audiences can engage with it is an example of ___ communication.

Answer: inclusive

Accepted answer(s): inclusive, accessible, multimodal

Q6 Type-in

A compression method where the file can be perfectly restored to its exact original with no data lost is called ___ compression.

Answer: lossless

Accepted answer(s): lossless

Q7 Multiple choice Non-routine

A student's portfolio publishes full playtester names next to blunt negative comments, in technical jargon, sourced from a hosting platform whose terms of use claim ownership of all uploaded content. A peer reviewer says: "just delete the negative comments so it looks better." Which response best addresses the actual problems?

Answer: Anonymise commenter names, simplify the language for a wider audience, and check the hosting platform's terms of use before uploading further content — rather than hiding negative feedback

Correct — this addresses the real issues (consent/privacy, accessibility of language, and data ownership) without dishonestly hiding legitimate feedback, which the peer's suggestion would do.

2. Researching and Planning

Foundation (D–E) (8 questions)

Q1 Multiple choice

A student plans their portfolio in stages — draft layout, get feedback, revise, get feedback again — rather than building the whole site once and hoping it's right. This is an example of:

Answer: An iterative approach

Correct — iterative means repeating cycles of build, review and revise, rather than doing it once.

Q2 Multiple choice

Early websites were mostly static text pages. Modern portfolio sites often include interactive elements like embedded video and clickable galleries. This shows that UIs have:

Answer: Evolved in response to people's needs and new opportunities

Correct — interfaces change over time as technology and user expectations develop.

Q3 Multiple choice

Asking a group of real visitors to try a portfolio site and note where they get confused is an example of:

Answer: A technique to evaluate a UI

Correct — observing real users interacting with the interface is a common UI evaluation technique.

Q4 Multiple choice

Keeping the same font, colours and button style on every page of a portfolio site is an example of applying which design principle?

Answer: Consistency

Correct — using the same visual style throughout is the design principle of consistency.

Q5 Multiple choice

A student looks at other students' portfolio sites from previous years to see what worked well before starting their own. This is an example of:

Answer: Evaluating existing UIs to inform a new design

Correct — reviewing existing examples to assess what's suitable is a planning technique.

Q6 Multiple choice

A game studio's portfolio uses a 360-degree virtual gallery visitors can 'walk through' using their phone. This is an example of:

Answer: An immersive experience using VR/AR-style technology

Correct — 360-degree, explorable environments are an example of immersive interactive media.

Q7 Multiple choice

Before designing, a student writes: "Employers need to quickly see what games I've made and judge my skill level." This is an example of:

Answer: Defining the real-world problem and describing the users

Correct — this identifies who the site is for and what problem it solves for them.

Q8 Multiple choice

A student sketches three different homepage layouts before picking one to build. This is an example of:

Answer: Generating alternative designs before selecting a preferred one

Correct — creating multiple options and comparing them is the definition of this process.

Core (C) (9 questions)

Q1 Multiple choice

A student builds their entire portfolio in one long session without showing anyone until it's "finished," then discovers major navigation problems too late to easily fix. What does this best illustrate?

Answer: The risk of not using an iterative, feedback-driven approach

Correct — without repeated small cycles of feedback, problems aren't caught until it's harder to change them.

Q2 Multiple choice

Which of these is the strongest technique for evaluating whether a portfolio's navigation is genuinely easy to use?

Answer: Watching real visitors attempt specific tasks and noting where they struggle

Correct — observing real task attempts reveals actual usability problems more reliably than opinion alone.

Q3 Multiple choice

A portfolio uses a bright red 'Download' button that stands out clearly from the rest of the page, while low-priority links are small and grey. This applies which design principle?

Answer: Visual hierarchy

Correct — deliberately making important elements stand out more than less important ones is visual hierarchy.

Q4 Multiple choice

A student evaluates a well-known game studio's press-kit website and decides one of its layout ideas (a filterable project grid) could be adapted for their own portfolio. What is this an example of?

Answer: Assessing whether an existing UI could be modified and reused elsewhere

Correct — this is exactly the process of evaluating an existing UI for suitability and adaptation.

Q5 Multiple choice

Compared to a normal 2D screenshot, why might an AR or VR-style interactive preview of a game add value to a portfolio?

Answer: It can let a visitor experience part of the game world more directly, rather than just viewing a static image

Correct — immersive technologies aim to create a more direct, experiential sense of the content.

Q6 Multiple choice

A student defines their real-world problem as: "Employers can't easily judge my skills from a resume alone; a portfolio lets me show, not just tell." Which part of this breaks the problem into a manageable part?

Answer: Identifying that showing evidence (not just describing it) is the specific gap to solve

Correct — this narrows a broad problem (proving skill) into a specific, addressable part (showing evidence).

Q7 Type-in

Creating several different possible design options and comparing them against the requirements before choosing one is called generating ___ designs.

Answer: alternative

Accepted answer(s): alternative

Q8 Type-in

An approach to project work where you repeatedly plan, build, get feedback and revise in cycles (rather than doing everything once) is called an ___ approach.

Answer: iterative

Accepted answer(s): iterative

Q9 Type-in

Deliberately making the most important element on a page (e.g. a call-to-action button) stand out more than less important elements is called visual ___.

Answer: hierarchy

Accepted answer(s): hierarchy

Extension (B–A) (7 questions)

Q1 Multiple choice

A student defines their problem clearly ("employers need fast evidence of skill") but then builds the whole site in one uninterrupted sprint with no check-ins. What is the most accurate critique?

Answer: A clear problem definition was undermined by not applying an iterative process during production

Correct — even a well-defined problem can lead to a poor solution if the build process skips feedback cycles.

Q2 Multiple choice

A student wants to evaluate whether their planned navigation structure will work before building it. Which is the strongest planning-stage technique?

Answer: Testing a low-fidelity prototype (e.g. a Figma clickthrough) with real users and comparing it against an existing UI they evaluated earlier

Correct — combining prototype testing with earlier UI evaluation gives evidence before committing to a build.

Q3 Multiple choice

A student generates three alternative homepage designs. Design A looks the most visually striking; Design B best matches the stated requirement that employers should find key projects within two clicks. Which should most influence the final choice, and why?

Answer: Design B, because it's evaluated against the actual requirement rather than visual appeal alone

Correct — generating alternatives is only useful if they're evaluated against the requirements, not just visual preference.

Q4 Multiple choice

A student argues that adding a VR gallery to their portfolio is unnecessary because "static screenshots have always worked fine." What is the strongest counter-argument grounded in how UIs evolve?

Answer: UIs evolve as new technology creates new opportunities to meet user needs better, so "always worked" doesn't mean it can't be improved

Correct — this directly reflects how UI evolution is driven by new opportunities, not just by past sufficiency.

Q5 Type-in

Judging whether an existing interface design is appropriate to reuse, and identifying what would need to change, is called ___ an existing UI.

Answer: evaluating

Accepted answer(s): evaluating, assessing

Q6 Type-in

Splitting a large, real-world problem into smaller, addressable parts before designing a solution is called ___ the problem.

Answer: defining

Accepted answer(s): defining, breaking down, decomposing

Q7 Multiple choice Non-routine

A student has 2 weeks left before their portfolio is due. They've generated three alternative homepage designs and evaluated an existing studio site for ideas, but haven't started building anything yet. A peer says: "just pick your favourite design and start building — there's no time left to plan properly." What is the strongest response?

Answer: Quickly select the design that best meets the stated requirements (informed by the earlier evaluation), then build and test in short iterative cycles rather than skipping planning altogether

Correct — this keeps the benefit of requirement-based selection and iterative feedback, just compressed into a shorter timeframe, rather than abandoning planning entirely.

3. Producing and Implementing

Foundation (D–E) (8 questions)

Q1 Multiple choice

A student builds their About page with a clear heading, a short paragraph, and a profile photo with alt text. This is best described as:

Answer: Designing and implementing a UI with functionality, accessibility and aesthetics in mind

Correct — this combines a working page (functionality), an accessible feature (alt text), and visual design (aesthetics).

Q2 Multiple choice

A student organises their site into clear sections — Home, About, Projects, Reflections — each with a consistent menu. This is an example of applying:

Answer: Information architecture

Correct — organising content into a logical, navigable structure is information architecture.

Q3 Multiple choice

Before adding the playtest survey to their site, a student decides not to collect names or emails, only ratings and comments. This shows they are considering:

Answer: Privacy and what data should be collected

Correct — deliberately limiting collected data to protect privacy is exactly this consideration.

Q4 Multiple choice

A survey rating (1–5) is stored as a whole number, while a written comment is stored as text. This shows the student is thinking about:

Answer: Selecting appropriate data types

Correct — choosing whole numbers for ratings and text for comments matches the data to an appropriate type.

Q5 Multiple choice

In their design journal, a student correctly uses terms like "functional requirement," "wireframe" and "user experience." This demonstrates:

Answer: Selecting and using specialist terminology in context

Correct — using the correct technical vocabulary accurately is exactly this skill.

Q6 Multiple choice

A student keeps a design journal noting design decisions, feedback from a teammate during game development, and how the site changed as a result. This is best described as:

Answer: A record of project development showing iterative and collaborative work

Correct — this documents both the iterative process and input from working with others.

Q7 Multiple choice

A student adds a link to their anonymous playtest survey on each project page so visitors can leave feedback. This is an example of:

Answer: Collecting data from users while considering privacy

Correct — gathering feedback anonymously (no names/emails) shows privacy has been considered.

Q8 Multiple choice

A playtest survey response has "7" entered for a rating that should only be 1–5. What should happen to this response?

Answer: It should be flagged as invalid and not included in the summary as-is

Correct — a value outside the valid range is invalid data and shouldn't be treated as a normal, correct response.

Core (C) (9 questions)

Q1 Multiple choice

A student's project page displays correctly and all links work, but visitors say the small grey text on a light grey background is hard to read. This is a failure of which UI/UX quality?

Answer: Accessibility (specifically, colour contrast)

Correct — poor colour contrast is a well-known accessibility issue, separate from whether the page functions correctly.

Q2 Multiple choice

A student's site has projects scattered across random pages with no consistent menu, so visitors get lost. Which is the most accurate diagnosis?

Answer: Poor information architecture

Correct — the underlying content organisation and navigation structure is the issue, not the visual style of any one page.

Q3 Multiple choice

A student wants to add a feedback survey but is unsure whether it's ethical to store visitors' IP addresses alongside their comments without saying so. What should guide this decision?

Answer: Being transparent about what data is collected and why, and avoiding unnecessary personally identifying data

Correct — privacy-conscious data collection means being clear about, and minimising, what personal data is gathered.

Q4 Multiple choice

A student is structuring their survey data so each response records: rating value, question type, and which project it relates to. This is an example of:

Answer: Modelling entities and their attributes using structured data

Correct — defining what information belongs to each response (entity) and its properties is data modelling.

Q5 Multiple choice

A student's design journal shows: "Teammate suggested simplifying the difficulty curve after our first playtest — implemented in build 2, retested, feedback improved." This entry most clearly demonstrates:

Answer: Both iterative development and documented collaborative input

Correct — it shows a repeat cycle (build, test, revise, retest) driven partly by a teammate's input.

Q6 Multiple choice

A summary of survey ratings shows an average "Fun" score of 3.4, but one response was actually "N/A" typed into a numeric field and got counted as 0 by mistake. What is the main risk this shows?

Answer: Invalid or incorrectly handled data can distort a summary and lead to a misleading conclusion

Correct — an incorrectly counted invalid entry pulls the average down inaccurately, which is exactly why validation matters.

Q7 Type-in

The way a website's content is organised and structured into pages, menus and categories so users can find things is called ___ architecture.

Answer: information

Accepted answer(s): information

Q8 Type-in

Defining what pieces of information (attributes) belong to a particular thing being recorded, like a survey response, is called ___ the data.

Answer: modelling

Accepted answer(s): modelling, structuring

Q9 Type-in

Checking that entered data falls within an expected range or format before it's accepted is called data ___.

Answer: validation

Accepted answer(s): validation

Extension (B–A) (7 questions)

Q1 Multiple choice

A student's site is technically functional and well-organised (clear information architecture), but user testing shows visitors still can't tell which project is the student's "best" work. What is the most accurate diagnosis?

Answer: A UX/design gap — structure is not the same as effectively guiding attention to what matters most

Correct — good organisation doesn't automatically mean the design communicates priority or emphasis to the user.

Q2 Multiple choice

A student's anonymous survey unintentionally logs visitors' browser type and approximate location alongside their ratings, without telling visitors. What is the most significant issue here?

Answer: Data is being collected beyond what was disclosed, undermining the 'anonymous, no Personally Identifiable Information' privacy intent

Correct — even without a name, extra data collected without disclosure conflicts with informed, minimal data collection principles.

Q3 Multiple choice

A student stores survey ratings as text (e.g. "3 stars") instead of numbers. What problem does this most directly cause later?

Answer: It becomes harder to validate, summarise or calculate an average from the data

Correct — text-based ratings can't easily be checked as in-range numbers or averaged without extra processing.

Q4 Multiple choice

Two students worked together on the same game, but only one documents any collaborative decisions in their design journal — the other's journal reads only "I did X, I did Y." What is the strongest critique of the second student's record?

Answer: It doesn't demonstrate how collaborative input shaped the iterative development, even if collaboration happened

Correct — a development record should show how working with others influenced decisions, not just list individual actions.

Q5 Type-in

Personal details that could identify an individual, such as a name or email address, are referred to as ___.

Answer: personally identifiable information

Accepted answer(s): personally identifiable information

Q6 Type-in

A spreadsheet feature that automatically calculates a single value (like an average or total) from a range of cells is called an ___ function.

Answer: aggregate

Accepted answer(s): aggregate

Q7 Multiple choice Non-routine

A student's survey is meant to be anonymous, but a review of the data shows: (1) browser/location metadata was logged without disclosure, (2) one rating value is out of the valid 1–5 range, and (3) two free-text responses appear to be duplicate test entries. A teammate says: "it's fine, just publish the average scores as they are." What is the strongest response?

Answer: Remove or disclose the undisclosed metadata, exclude the invalid and duplicate/test entries from the summary, then recalculate before publishing

Correct — this addresses the privacy issue (undisclosed data), the validity issue (out-of-range value) and the data-quality issue (test/duplicate entries) before the summary is trusted and published.

4. Testing and Evaluating

Foundation (D–E) (8 questions)

Q1 Multiple choice

A student checks their finished site against the original list of functional and non-functional requirements they wrote earlier. This is an example of:

Answer: Evaluating the project against previously developed requirements

Correct — comparing the finished product to the original requirements is exactly this kind of evaluation.

Q2 Multiple choice

A student checks whether their published survey still keeps visitor responses anonymous and whether their site properly credits any images they didn't create. This is an example of evaluating:

Answer: Social, ethical and legal responsibilities

Correct — privacy and proper attribution/credit are ethical and legal considerations.

Q3 Multiple choice

A student watches a visitor try to find a specific project and notices they click the wrong menu item twice before succeeding. This helps evaluate:

Answer: The usability of the UI

Correct — observing where a real user struggles is directly testing usability.

Q4 Multiple choice

A student notices their homepage takes several seconds to load because of large uncompressed images. This is a problem with the UI's:

Answer: Efficiency

Correct — how quickly and smoothly the interface performs is its efficiency.

Q5 Multiple choice

A student adds captions to their embedded gameplay video and checks the site still makes sense with images turned off. This helps evaluate whether the UI:

Answer: Conveys information effectively to a variety of audiences

Correct — testing with different access needs in mind checks whether the site communicates to a broad audience.

Q6 Multiple choice

A student researches the difference between a "UI designer" and a "UX researcher" role at a game studio. This is an example of:

Answer: Exploring careers in UI design or interactive media

Correct — investigating specific industry roles is exactly this kind of exploration.

Q7 Multiple choice

A student compares their finished portfolio to the original functional requirement "visitors must be able to click a thumbnail to open the full project." They confirm this works. This is an example of:

Answer: Evaluating the project against a functional requirement

Correct — directly checking a built feature against a stated functional requirement is this type of evaluation.

Q8 Multiple choice

During evaluation, a student writes in their journal: "My teammate suggested I test the survey link on mobile too — good catch, I fixed a broken link." This is an example of:

Answer: Reflecting on collaborative work practices during evaluation

Correct — this documents how a peer's input contributed to improving the finished product.

Core (C) (9 questions)

Q1 Multiple choice

A student's site meets every functional requirement (all pages exist, all links work) but fails the non-functional requirement that pages load in under 3 seconds. What should the evaluation conclude?

Answer: The project is only partially successful, since non-functional requirements matter as much as functional ones

Correct — a complete evaluation checks both types of requirements; meeting only functional ones isn't full success.

Q2 Multiple choice

During evaluation, a student realises their portfolio still displays a playtester's full name from an early draft, despite the later decision to keep the survey anonymous. What is the most appropriate response?

Answer: Remove the identifying detail before publishing, since it conflicts with the stated ethical/privacy approach

Correct — leaving identifying data in place after committing to anonymity is an ethical and privacy failure that should be corrected before publishing.

Q3 Multiple choice

Testing shows visitors can find every project (good usability) but the page takes 8 seconds to load large uncompressed screenshots (poor efficiency). Which statement is most accurate?

Answer: Usability and efficiency are separate qualities, and a UI can succeed at one while failing the other

Correct — this scenario shows exactly that: good navigation clarity doesn't guarantee good performance, and vice versa.

Q4 Multiple choice

A student's project descriptions are written only in advanced game-design jargon with no plain-language summary. Evaluating this against "conveys information to a variety of audiences," what is the fairest conclusion?

Answer: It likely fails for audiences without game-design background, such as a general employer or recruiter

Correct — jargon-only content excludes audiences who don't share that specialist vocabulary, which is exactly what this criterion tests.

Q5 Type-in

Testing how easily and comfortably real users can complete tasks with an interface, to find and fix problems, is called testing for ___.

Answer: usability

Accepted answer(s): usability

Q6 Type-in

Testing how quickly and smoothly a UI performs, such as page load time, is called testing for ___.

Answer: efficiency

Accepted answer(s): efficiency

Q7 Multiple choice

A student compares job listings for "UX Designer" and "Front-End Developer" at game studios and notes that one focuses more on research and wireframes, the other more on coding the interface. This comparison is most useful for:

Answer: Understanding how UI/UX skills map onto different real industry career paths

Correct — comparing role responsibilities is exactly how career exploration connects classroom skills to industry paths.

Q8 Multiple choice

A student's evaluation notes: "Without my partner pointing out the confusing nav menu during our playtest session, I wouldn't have caught it before submission." This best demonstrates:

Answer: The value of collaborative feedback in the evaluation process

Correct — this explicitly credits a peer's contribution to identifying and fixing a problem.

Q9 Type-in

Checking whether a solution meets social, ethical, legal and cybersecurity responsibilities — not just whether it works — is part of a ___ evaluation.

Answer: responsible

Accepted answer(s): responsible, ethical, thorough

Extension (B–A) (7 questions)

Q1 Multiple choice

A student's site meets all functional and non-functional requirements, and appears to meet ethical/legal responsibilities on the surface. A closer check finds an embedded image was taken from another website without credit. What does this reveal about evaluation?

Answer: Meeting stated requirements doesn't automatically mean all ethical/legal responsibilities have been met — these need separate checking

Correct — this scenario shows a real gap between technical requirement-checking and a full ethical/legal review.

Q2 Multiple choice

A peer review of a student's site notes it works well for tech-savvy visitors but excludes visitors using screen readers, since images have no alt text. The student's collaborator disagrees, saying "screen reader users are a tiny audience, it's not worth fixing." What is the strongest evaluation-based response?

Answer: Conveying information to a variety of audiences is an explicit evaluation criterion, so excluding any audience group is a genuine gap regardless of its size

Correct — the criterion is about reaching a variety of audiences, not just the majority, so this is a legitimate finding to document and address.

Q3 Multiple choice

A student researching UX careers finds that "performance/efficiency testing" is listed as a core skill for a UX QA tester role. How does this connect their testing work to the career exploration content?

Answer: The testing skills they're practising (like efficiency testing) directly reflect real industry roles and responsibilities

Correct — this draws a genuine connection between the specific classroom skill and its real-world professional application.

Q4 Type-in

Practices that protect systems and data from unauthorised access or misuse are referred to as ___ principles.

Answer: cybersecurity

Accepted answer(s): cybersecurity

Q5 Type-in

Reviewing a peer's work and providing constructive feedback on it, as part of documenting how a team worked together, is an example of ___ practices.

Answer: collaborative

Accepted answer(s): collaborative

Q6 Multiple choice

A student's usability testing shows visitors complete tasks correctly, but several mention the process "felt slower and more frustrating than it should." All functional requirements are technically met. What does this suggest about the evaluation?

Answer: Meeting functional requirements doesn't guarantee a good usability experience — subjective ease-of-use matters too

Correct — visitors succeeding at tasks but still finding it frustrating shows usability is about more than just task completion.

Q7 Multiple choice Non-routine

Final evaluation of a student's portfolio finds: (1) all functional requirements are met, (2) one embedded image lacks proper credit, (3) alt text is missing on several images, and (4) the design journal documents only individual work despite a teammate contributing ideas during game development. A rushed peer says: "functional requirements are met, so it's basically done — ship it." What is the strongest response?

Answer: Meeting functional requirements alone isn't sufficient — the ethical/legal (credit), accessibility (alt text) and collaborative-documentation gaps should all be addressed before the evaluation is considered complete

Correct — a genuine evaluation checks functional requirements, non-functional/ethical/legal responsibilities, accessibility for varied audiences, and accurate documentation of collaborative work — not just one of these.
