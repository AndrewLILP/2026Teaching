E-Portfolio UX — Topic Review Notebook

📋 Student Game Design e-portfolio — quick reference

You don't need to memorise these details — refer back here any time. The questions are testing computing theory, not your memory of the project.

Purpose
Showcases the student's shipped/prototype games and design journal, framed as a simulated job-application portfolio
Structure
Home, About, Project 1, Project 2, Reflections — simple nav bar (flexible per student)
Project page content
Screenshots, embedded video, written reflection, downloadable build, link to itch.io / Unity Play
Build tools
HTML + CSS; Figma (and/or AI-prompted prototypes) used for design first
Feedback survey
Anonymous playtest survey per project — 4 rating-scale questions (Fun, Controls, Difficulty, Retention, each 1–5, higher = better) + 4 short open-ended questions (Highlights, Frustrations, Expectations, Changes)
Data handling
Survey responses collected from playtesters; no names or emails collected — ratings and free text only
Accessibility
General UX/accessibility theory (alt text, colour contrast, responsive layout, consistent navigation)
