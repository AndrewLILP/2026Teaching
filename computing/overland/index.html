Stage 5 · Software Development

Overland Studio

Six weeks. One wagon. A hundred ways to fail before dinner.

Students build a text-based resource-management simulation in Python — a state dictionary, a day-by-day loop, and a string of random disasters standing between the party and the far coast. Every lesson runs live in Grok Learning; no installs, no file saves, just the console.

Stage 5 · Year 10 Python · console Grok Learning 6 lessons · 1 sprint
Lesson 1 · Identifying & Defining

What makes a trail game work?

Pull apart existing text-based resource-management games, then define the brief for the party's journey west.
Lesson 2 · Researching & Planning

Packing the wagon in pseudocode

Design the state dictionary and pseudocode the day-by-day loop before a single line of Python is written.
Lesson 3 · Producing & Implementing — Sprint A

The core loop

Build the day counter, the travel function, and the status checks that decide whether the party is still moving.
Lesson 4 · Producing & Implementing — Sprint B

Everything that can go wrong

Wire in random events with the random module, and design console feedback players can actually read.
Lesson 5 · Testing & Evaluating

Desk-check the disaster

Trace the state through a full playthrough by hand, then test the real game against the brief.
Lesson 6 · Showcase & Extension

The far coast

Extend the game with a tiered creativity task, then present the finished trail to the class.
