Chapter 3: Adding & Subtracting Fractions

MA4-FRC-C-01 · Chapter 3 of 5

Fill the bar exactly

Hook

In music, a 4/4 bar has to add up to exactly one whole note.
A semibreve lasts a whole note: 1.
A minim lasts a half note: 12.
A crotchet lasts a quarter note: 14.
A quaver lasts an eighth note: 18.

Using any combination of these note values, how many different ways can you fill a bar so the note lengths add up to exactly 1?
Try to find at least three different combinations before revealing the answer.

Here are five combinations that all add up to exactly 1:

4 crotchets: 14 + 14 + 14 + 14 = 1
2 minims: 12 + 12 = 1
1 minim + 2 crotchets: 12 + 14 + 14 = 1
1 minim + 1 crotchet + 2 quavers: 12 + 14 + 18 + 18 = 1
8 quavers: 18 × 8 = 1

Every one of those is a fraction addition problem with unrelated denominators.
This chapter is about making sure you can add and subtract fractions like these confidently, no matter what denominators show up.

Learn

I Do

Same-denominator addition and subtraction

When two fractions share the same denominator, you simply add or subtract the numerators and keep the denominator the same.

38 + 28 = 58

We Do

Unrelated denominators

Now try 13 + 14.
The denominators are different, so we can't just add the numerators.
What's the smallest common denominator we could rewrite both fractions over?

The lowest common denominator (LCD) of 3 and 4 is 12.
13 = 412 and 14 = 312.
412 + 312 = 712.
I Do

A common misconception

It might seem tempting to add numerators and denominators separately, like this:

23 + 14 ≠ 37

This doesn't work, because it changes the size of each fraction rather than combining their actual values.
Rewriting both fractions with the same denominator first keeps each fraction's true value intact.

23 + 14 = 812 + 312 = 1112

We Do

Adding mixed numbers

Add 123 + 214.
Start by rewriting the fractional parts with a common denominator, then combine the whole numbers separately.

LCD of 3 and 4 is 12.
123 = 1812 and 214 = 2312.
1812 + 2312 = 31112.
I Do

Subtracting a fraction from a whole number

To subtract a fraction from a whole number, first rewrite the whole number as a fraction with a matching denominator.

5 − 23 = 153 − 23 = 133 = 413

We Do

Back to the bar

A composer has written 34 of a bar so far.
How much of the bar is left to fill?

1 − 34 = 44 − 34 = 14
There's a quarter of the bar left — exactly enough space for one crotchet.

Reflect

Key ideas from this chapter

Fractions with the same denominator can be added or subtracted by combining the numerators directly.
Fractions with different denominators must first be rewritten over a common denominator, which keeps each fraction's true value intact.
A whole number can be subtracted from by rewriting it as a fraction with a matching denominator first.

Extension: a non-routine challenge

Can a unit fraction (a fraction with numerator 1) always be written as the sum of two different unit fractions?
Which unit fractions can be written this way in more than one way?
Which unit fractions can only be written this way in one way, if any?

There's no single fixed method for this one — try a few unit fractions like 12, 16, and 112 and look for a pattern.
